CompareStation 1.8.0 — 免安装使用说明
=====================================

1. 直接运行

   双击 CompareStation.exe。程序不写系统目录，也不需要安装。

2. 把 CompareStation 加进资源管理器右键菜单（可选）

   本包不提供安装程序。要获得「Compare with CompareStation」右键项，在本目录打开
   PowerShell 7 执行：

       pwsh -NoProfile -File .\RegisterExplorerCommand.ps1 -InstallRoot .

   它会为当前用户注册 .mp4 / .mkv / .mov / .avi / .m4v 的右键命令，写入
   HKCU\Software\Classes，不需要管理员权限。选中 1–3 个视频后右键即可一键打开或对比；
   选中目录、网络路径或超过 3 个文件时该项自动隐藏。

   取消注册：

       pwsh -NoProfile -File .\RegisterExplorerCommand.ps1 -Uninstall

   两点注意：

   - 注册记录的是本目录的绝对路径。移动或删除本目录后右键项会失效，重新执行上面的
     注册命令即可。
   - Windows 11 把这类命令放在右键菜单的「显示更多选项」里。

   脚本要求 PowerShell 7（pwsh）；Windows 自带的 Windows PowerShell 5.1 不支持。

3. 未签名

   可执行文件未签名，Windows 可能提示 Unknown Publisher 或 SmartScreen。发布页同时提供
   SHA256SUMS.txt，可用来校验下载的压缩包是否完整。
