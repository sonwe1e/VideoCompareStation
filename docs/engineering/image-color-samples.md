# 图片颜色与像素样本设计（P2/P3 输入，尚未实现）

状态：设计稿。本文只固定“要准备哪些样本、验收口径怎么算”，不表示颜色管理、ICC 解析或
任何显示路径变更已经实现。当前行为的权威描述在
[产品目标 §4](../product/visual-review.md) 与
[问题台账](visual-review-backlog.md) 的图片条目。

## 1. 现有口径（实现事实，P2 必须保持不变的部分）

- 探针读数来自**已解码显示缓冲**（RGBA8）；「归一化浮点」是 `channel/255` 的显示格式，
  不改变采样值、差异或统计。
- 高位深来源（如 gray16be）另带**解码转换后的 RGBA64 sidecar**；「转换后 16-bit」的
  数值与 Alpha 过滤比较都取该 sidecar（`T/255` 在 16-bit 上以整数精确计算），仅在两侧
  均有同尺寸 sidecar 且未重采样时出现。它不是文件原始平面值。
- 差异统计（MAE/峰值/Alpha 差）是**原始 8-bit 差值**；`diffGain`（1–16）只放大显示变体，
  不重算统计。
- 透明像素的 RGB 取直通 Alpha 缓冲中的真实值，不因 Alpha 小而归零；Alpha 过滤仅作用于
  「RGB 忽略透明」观察，且为严格 `A > T`。
- 中性棋盘格 `#272727`/`#404040` 只影响显示背景，不进入任何读数。

## 2. 样本矩阵

### 2.1 自动化小样本（进仓库，供测试与 CI）

| 类别 | 样本 | 检查目的 | 现状 |
|---|---|---|---|
| 普通图片 | RGB8 PNG/JPEG、灰阶 | 基础行为与位深标注 | 既有测试注入图覆盖；缺仓库内真实编码样本 |
| 透明 | Alpha 0 / 接近 0 / 中间值 / 255；透明区含非零 RGB | 不丢透明像素真实通道值；过滤器边界 | `tests/component/ui` 注入图覆盖数值路径；缺真实 PNG 编码样本 |
| 高位深 | 16-bit 渐变；仅低位不同的图片对 | 显示降位深不能漏检；16-bit 统计出现条件 | 既有 gray16be 用例在工作区测试中；待固化为命名 fixture |
| 色彩配置 | sRGB、Display P3、Adobe RGB、无配置、损坏配置 | P3 解析与回退行为 | **全部缺失**，P3 前必须补齐 |
| 大图 | 2K；当前允许范围内的压力样本 | 首次处理、取消、内存 | 部分由注入图尺寸覆盖；缺真实编码大图 |

### 2.2 真实素材（手工/硬件验收，不进仓库）

沿用与 P4 相同的固定素材纪律：同一素材、GPU、驱动、显示器刷新率。需要覆盖：

- 双源/三源 1080p60 视频（P4 性能矩阵）；
- 真实 ICC 显示器环境下的图片显示（P3 显示层验收）；
- Advanced Color（HDR 桌面）开启与关闭的系统状态（只做“明确状态提示”验收，不承诺转换正确性）。

## 3. P3 之前必须敲定的口径问题

1. **状态枚举**：有效配置 / 无配置但有可信声明 / 无色彩信息（假设 sRGB 并标注） /
   配置损坏或不支持 / 显示器状态变化。每个状态在 UI 上的可见文案与可用的观察路径
   （回退到未转换）必须先定义。
2. **引擎选型判据**：Qt `QColorSpace`/`QColorTransform` 与 Little CMS 2 的比较必须用
   同一组样本 + **独立参考值**（不由待测实现生成）；给出每样本的数值容差与判定方法。
3. **Alpha 规则**：颜色转换只作用于颜色通道；预乘只允许发生在显示边界；棋盘背景合成
   所用颜色空间必须写明。
4. **Windows 输出链路**：应用内转换到 sRGB ≠ 显示器上正确显示。需要核对系统 Advanced
   Color 状态、窗口所在显示器、Qt Quick 输出表面解释，避免 ICC 双重套用。第一期只对
   经过验证的路径声明支持。
5. **口径不变的证明方法**：任何颜色功能默认不影响既有读数/统计/差异；需要一个开关往返
   测试（开→关→开）断言全部数值逐位不变。

## 4. 验收分层（沿用用户方案）

- 数值层：已知色块、灰阶、透明边缘、高位深渐变与独立参考值比较；
- 行为层：开关、换图、取消、跨屏、配置变化、原统计不变；
- 显示层：受支持环境的实际窗口观察与输出路径确认；截图只证明布局与明显异常，
  不证明物理显示颜色。

## 5. 与探针接线的关系

探针的数值格式与复制颜色已经过 P1 试点接线（见
[QML 接口试点验证](qml-interface-pilot.md)）；本设计不改变探针语义，只为其后的颜色管理
提供样本与判据。实现顺序按用户方案：先 P2 数据契约与等价迁移，再 P3 SDR 颜色管理。
