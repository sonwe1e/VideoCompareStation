# 可复现证据记录

本页定义记录方法。各版本结果只在 [发布记录](../releases/) 或相应专题中保存；
当前待验事项见 [问题台账](visual-review-backlog.md)。旧机器配置、测试数量和 ZIP 路径
不会自动成为新任务的基线，同版本号的不同构建也不能共享验收结论。

## 一次验证需要记录什么

| 身份 | 必要内容 |
|---|---|
| 源码 | 完整提交 SHA、工作区差异、验证前后是否又改动了相关文件 |
| 构建 | preset、构建类型、实际工具链及依赖版本；验证包时记录 ZIP 与运行文件的 SHA-256 |
| 执行 | 原始命令、实际选中/执行/通过/失败/跳过/禁用数量、退出码与日志路径 |
| 素材 | 路径或清单身份、SHA-256、容器/编码、位深、帧率或时间线、分辨率、Alpha/颜色声明 |
| 显示与性能 | GPU/驱动、物理显示器与连接、刷新率、DPI、多屏拓扑、HDR/Advanced Color、ICC、物理或远程呈现路径 |
| 条件 | 比较模式、倍率、播放策略、预热和排除区间；性能记录使用 runner 协议 |

工具发现与构建只走 [构建包装器](../building.md)。临时探针、日志与截图放
`out/verification/<任务>/`，正式测试留在 `tests/`。发布或后续步骤消费文件前读回确认，
避免旧路径中残留的上一份产物被误认成本次结果。

## 样本出处

| 清单 | 用途 |
|---|---|
| `tests/fixtures/manifest.json` | 视频编码、VFR、B 帧、非零起始时间与损坏输入 |
| `tests/fixtures/images/color/manifest.json` | ICC、灰阶、透明边缘、高位深与独立颜色参考 |
| `tests/fixtures/images/formats/manifest.json` | 图片格式和不支持编码的报错验证 |

清单描述仓库样本；它不证明某个发布包已完整运行这些样本。真实大素材不入库，记录来源与哈希。

## 用户工作流复现

按本次影响面选择：打开单素材；A/B 同一区域比较；记录后重开恢复；导出后独立读回。
每条记录实际入口、操作、预期与观察结果。自动化、人工走查和真实硬件测量分别陈述，
失败、未测与环境跳过分开记录；零项执行不算通过。

可见窗口与硬件使用 [测试环境约定](test-environment-separation.md)，
物理显示和播放性能遵循 [runner 协议](../self-hosted-runner.md)。
WARP、截图或虚拟显示器不能证明物理显示颜色和 D3D11VA 长播性能。
