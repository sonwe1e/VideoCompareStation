# CompareStation 五类工作区视觉与布局方案

日期：2026-10-24；状态校正：2026-10-25。P0–P6已随 `9640b52` 合入，
后续 `377cb2a` 与 `d3ce2a9` 收敛背景选择器、同名任务标签和图片来源pill。
本页保留布局设计依据，不重新开启实施批次；当前缺口见台账DPI-01/UX-13。
弹窗轻阴影为有意推迟项。历史截图在 `out/verification/ui-redesign-2026-10-24/`，
只证明对应版本与环境，不代表所有高DPI/真实工作流验收完成。

用户已认可上一轮“中性深灰、统一比例、减少大面积胶囊、画面优先”的探索方向，并要求进一步覆盖图片打开／查看、视频打开／查看、图片对比、图片编辑、视频对比。用户明确将“视频编辑”更正为“视频对比”，本计划不新增视频编辑器。

本文的区域安排、尺寸与默认值是推荐方案。已有产品语义继续有效；不能把本文件中的建议提前登记为已实现或用户逐项批准。范围包括共用打开入口、五个工作区、文件侧栏、检查器、弹窗、窄窗与异常状态；下文保留设计时的建议与尺寸依据；后续实现已落地，不能将原建议当作尚未开工。

## 1. 原设计基线、观察依据和判断

- 设计时基线：`b2f08b8`（2.5.2）加当时工作区的任务标签与比较对入口；这些实现现已合入，历史截图不代表当前导航。
- 当前依据：[产品目标](../product/visual-review.md)、[决策登记册](../engineering/decision-register.md)、[Agent 路由](../agent-guide.md)、实际 QML 实例化与控件条件。
- 视觉依据：用户提供的两张真实使用截图，以及 `out/verification/ux13-s5-final/` 的图片查看、并排、差异、编辑、视频局部联动和窄窗截图。后者生成于 2026-10-22，早于最近的标签／选对变更；只用来观察版式与控件组织，不作为当前完整行为或播放性能证据。黑色视频画面属于该组取证素材，不能据此判定产品黑屏。
- 设计时只核对源码与已有截图；实施批次后来补充了截图和自动验证，当前仍待实机验证的范围以问题台账为准。
- 第一张用户截图中的大播放面板看起来是 `123.png` 内的内容；图片工作区没有该播放面板，不能把它算作该工作区新增的浮层。

**核心判断：功能分类与视觉分类没有对齐。** 来源、任务、动作、观察模式、参数、读数使用了相似的填充和圆角；多个独立工具条依次叠加，使后加的能力不断争夺顶部空间。改版以稳定区域和有条件的参数面板为主，配色调整为辅。

三个具体切入口：

1. 将“任务标签”和“任务里的素材来源”分成不同外观、不同位置；来源不再看起来像第二套任务标签。
2. 把图片编辑拆成工具选择与工具参数两部分；保留当前工具可见，不让低频能力消失在无法辨认的更多菜单中。
3. 视频时间控制与画面观察控制分别成区；比较对始终显式，诊断信息从画面上的长句收敛到状态与检查器。

## 2. 共用外壳：每个区域只承担一种主要职责

从上到下安排如下。尺寸全部为 **Qt 逻辑像素**，是首轮排版起点，不是对现有截图物理像素的测量，也不是用户已指定的验收数字。

| 区域 | 放在哪里 | 内容与排列 | 建议尺度 |
|---|---|---|---|
| 系统标题与全局菜单 | 最顶端 | 保留 Windows 窗口控制；文件／对比／分析／视图／设置／帮助继续可发现 | 标题栏服从系统；菜单约 28 高 |
| 任务标签 | 菜单下方，贯穿窗口 | 一个标签代表一次审查任务；标题、未保存标记、关闭；活动标签接入下面的工作区 | 36 高；标题约 160–240 宽，长名省略并可查看全文 |
| 任务命令栏 | 标签下方，贯穿窗口 | 左侧打开／添加；中部当前工作区的模式；右侧输出、检查器、更多 | 40 高；必要时进入明确的紧凑排布，避免任意 Flow 换出第三行 |
| 左侧辅助区 | 命令栏下方、画布左侧 | 查看时是文件与历史；编辑时改为工具栏；两者不同时占左侧 | 文件栏沿用固定 232；编辑工具栏建议 64 |
| 来源行 | 中央工作区顶部，紧贴画布 | A/B/C、文件短名、主时间线／参考身份；两图或三视频使用同一对齐基线 | 32 高，A/B/C 标记约 18–20 方形 |
| 画布 | 中央剩余空间 | 原图、比较结果、ROI、必要的选择框；按原比例显示 | 自适应剩余空间，不规定虚假的统一占屏百分比 |
| 右侧参数／检查器 | 画布右侧 | 当前观察或编辑参数、指标和信息；按需展开 | 沿用 288 默认，260–320 可调范围 |
| 视图工具条 | 画布下沿、时间控制区上方 | 适应窗口、100%、当前缩放、框选放大、重置、网格；视频另有采样 | 36 高；控件命中区至少沿用 32 |
| 时间控制区 | 仅视频，视图工具条下方 | 时间轴、时间码、播放与逐帧、速度、连续性策略；区间操作在次行 | 核心约 88 高；区间行约 32；附加帧条按需展开 |
| 像素读数区 | 图片常驻；视频沿用探针入口 | 坐标、来源、数值、数值格式、复制；空间不足使用预留第二行／现有详情机制 | 单图约 36；双图预留约 60，不随悬停来回改变画布高度 |
| 状态栏 | 最底部 | 当前模式、观察口径、精确性／颜色限制、简短操作结果 | 24–28 高；异常可展开，普通读数不铺大色块 |

中央来源行、视图条、时间轴使用同一左右边界。文件侧栏顶端对齐来源行；参数面板顶端对齐来源行。面板通过一条分隔线和表面明暗与画布区分，不再套一个大圆角卡片。

任务标签统一视觉与排列规则，不借此次改版合并图片／视频后台宿主，不引入混合任务或后台解码。一个标签内 A/B/C 的选择仍是来源／观察操作，不是切换审查任务。

**高度预算示例：** 以 900 高的应用内容区、菜单 28、标签 36、命令 40、来源 32 为例，顶部合计 136。图片查看再留视图 36、读数 36、状态 24，画布可用高度约 668；视频含视图 36、核心播放 88、区间 32、状态 24，画布约 584。这里只验证布局预算有余量；文字换行、窗口装饰、特殊状态和附加面板需实测，不能据此声称画面面积已经增加某个百分比。

## 3. 比例、颜色、形状与文字

### 3.1 比例和间距

- 间距沿用 4／8／12／16 梯度：同组控件间 4，相邻功能组间 12–16，面板内边距 12–16。画布外框约 12，避免重复叠加父子 margin。
- 常规按钮视觉高度 28–32，实际点击范围至少 32；播放按钮 40。主按钮不通过显著增大高度表达重要性。
- 正文与操作标签 13–14；辅助文本 12；组标题 14–16。字体优先沿用 `Segoe UI Variable Text` 与现有中文回退；数值用现有等宽字体／表格数字，不把全部文件名也改成等宽。
- 文件行建议 40–44；只有存在有用的第二行元信息时采用两行。不能用空的辅助文字撑高列表。
- 每一个面板建立统一的左边线和字段标签宽度。相邻输入框的基线、单位列、展开箭头对齐。

### 3.2 色板建议

| 角色 | 首轮建议 | 用途 |
|---|---|---|
| 画布外部留白 | `#111111` | 安静的素材外区域；视频黑边仍按显示语义处理 |
| 窗口基础表面 | `#202020` | 菜单、任务背景 |
| 工具区与面板 | `#252525` | 通过轻微明度差区分结构 |
| 悬停／输入底 | `#303030` / `#333333` | 有交互含义的局部底色 |
| 分隔线 | `#383838` | 1 px 结构边界，避免重描边 |
| 主文字／次文字 | `#ECECEC` / `#B0B0B0` | 用明暗表达主次，保留现有对比度门禁 |
| 活动文字／活动浅底 | `#8BB9FF` / `#293748` | 当前模式、选中状态；不作为所有正常信息的背景 |
| 主要动作实底 | 首轮沿用 `#0964D4` 配亮字 | 空态“打开文件”、编辑“另存副本”等明确提交动作 |

这套建议只改变应用 chrome，不能顺带改变差异热力图标尺、原图像素、Alpha 合成、ICC 转换或导出图内容。棋盘格先保留已有中性双色，优先减少素材范围外的棋盘暴露面积；若后来调整棋盘明度，必须单独核对透明边缘观察样例。

A/B/C 沿用已有蓝青／橙／紫映射，但缩小为字母标记或局部细线，不给整张文件卡染色。参考源和主时间线同时使用文字，不仅靠颜色。警告黄用于确有偏差、无法精确对应或需要处理的限制；“尚未测量”使用中性文字，不能显示成“正常”或“零缺陷”。

### 3.3 形状承担语义

| 类型 | 形状与状态 |
|---|---|
| 普通动作 | 默认透明，悬停出现弱底色；4–6 圆角 |
| 模式组 | 一条共用分段区域；仅选中项有浅底；标签明示当前模式 |
| 下拉选择 | 中性输入底，统一箭头位置；不能与普通状态文字混淆 |
| 文件／来源标识 | 文件行或小标签；字母标记方形小圆角；去掉粗彩边与胶囊外形 |
| 任务标签 | 平直底边、轻圆角上边、活动下划线；与来源标签一眼可区分 |
| 数值／状态 | 默认纯文本；用列、间距和分隔线组织，不给每个字段套按钮底 |
| 弹窗／临时面板 | 8–10 圆角、实底、轻阴影；可读性不依赖后方素材颜色 |
| 键盘焦点 | 保留清楚的焦点轮廓；不能只因为鼠标点击就给控件留下持久粗边 |

## 4. 共用打开入口与空态

保持已经合并的“打开文件…”主入口，不重新建立“打开视频”“打开图片”两套平行全局入口。

- 空态中心是一组内容宽约 420–480 的轻量区域：一句说明、一个“打开文件…”主按钮、下面“打开文件夹…”和“对比文件夹…”两个次入口。现有“打开图片对…”保留为次级快捷入口或文件菜单项，不与主按钮争权重。
- 下面用一行说明多选规则：单文件查看；两图比较；2–3 个视频比较；混选或不支持的数量明确解释，不静默丢文件。
- 最近打开使用安静的文本列表，最多先展示少量已存在记录；不新增媒体库、推荐卡片或编造最近项。
- 打开成功后进入对应任务。新任务、加入当前比较、只替换 A/B、再次打开已有任务的行为沿用现有契约；菜单文案明确区分这些动作。
- 加载与恢复使用任务内状态行，保留上一已提交画面；错误在当前任务附近说明文件与原因，并提供重新选择入口。
- 拖入态用临时整窗提示，放下后恢复原布局，不保留装饰性拖放框。

## 5. 图片打开／单图查看：保留图像观察的直接入口

| 位置 | 放置内容 | 显示规则 |
|---|---|---|
| 命令栏左 | 打开／添加、换图 | “添加 B”与“替换 A”语义分开；不把只换 A 误接成新单图任务 |
| 命令栏中 | `RGBA / Alpha / 忽略透明`，背景选择，Alpha 过滤入口 | 宽窗保留三个通道的一步切换；紧凑档可用显示当前值的通道下拉。背景收成带文字的选择器，保留深色／棋盘／黑／白 |
| 命令栏右 | 编辑画面、检查器、更多 | 编辑是明确的模式入口，不能与通道按钮混在同一分段组 |
| 来源行 | A、文件名、尺寸；必要时标注显示转换状态 | 来源行优先承担文件身份；画布里的重复大信息卡收敛为最小标识 |
| 左侧 | 可打开的文件／历史或已存在的图片目录导航 | 保留不同模型的实际能力，不承诺图片目录拥有尚未接入的视频历史能力 |
| 画布 | 保持比例的图片、必要十字线、坐标与选区 | 外部留白中性灰；棋盘限于图像／透明合成观察范围；不改原始读数 |
| 视图条 | 适应窗口、100% 真实尺寸、实际百分比、框选、重置、网格 | 图片 100% 与视频物理像素映射的既有说明保持区分 |
| 底部读数 | A、坐标、Hex、RGBA、Alpha、整数／浮点、复制颜色 | 整数／浮点与 RGB/RGBA/Hex 复制入口常驻；鼠标离开画布后保留同代次最后有效样本 |
| 底部状态／详情 | 显示缓冲、转换开关、文件颜色配置、显示环境未验证 | 简短口径常驻；解释性文字展开，不把“未验证”简化成绿色通过 |

Alpha 过滤在入口上显示开关与阈值摘要；展开后出现滑块、数值、重置。开启后的“仅显示 A > T”留在画布外的参数摘要中，读数被隐藏时保留对应说明。不得让过滤、背景和颜色转换改变采样或统计语义。

## 6. 图片对比：模式、参数、读数各归其位

命令栏推荐顺序：

`打开／添加　换图　对调 A/B　｜ 单图 A/B　并排　分割线　淡化　差异 ▾ ｜ 编辑…　检查器`

来源行分列 A 和 B 的文件身份。并排画布使用等宽单元、统一边距和一致的标签基线；显示不同尺寸图片时保留真实尺寸关系，不通过 CSS/QML 拉伸制造看似对齐。

| 模式／能力 | 主操作放置 | 参数与解释放置 |
|---|---|---|
| 单图 A/B | 模式按钮常驻，当前来源在来源行显式显示；保留点击／空格切换 | 不重新增加已删除的重复“切至 A／B”大按钮 |
| 并排 | 模式按钮常驻；画布两等分 | 联动缩放／平移继续沿用，底部 A/B/Δ 读数按固定列排列 |
| 分割线 | 模式按钮常驻；画布只留下可拖动分割线和必要手柄 | 方向与比例放在贴近模式的短参数区；保留 W 与方向快捷键 |
| 淡化 | 模式按钮常驻 | A/B 比例滑块放在画布下方参数带，与视图工具条合并安排；不漂在图像内部 |
| 差异 | 菜单保留绝对差异、带符号差异、高亮、Alpha 差异 | 增益收成一个显式选择器；“按住看 A/B 原图”保留可持续按住的实体按钮，不能藏进普通菜单 |
| 差异统计 | 在右侧检查器“对比”页显示 | 指标表、参与像素、RGB／Alpha 口径、位深／重采样限制；不把长统计句常驻覆盖整张图 |
| 通道与背景 | 来源行旁的观察设置区或第二组短参数区 | 与单图保持同样的命名、当前值和快捷键；窄档只折叠呈现，不删除能力 |
| 不同尺寸与重采样 | 画布上方持久提示条 | 提示为什么当前不可比，明确操作“开启重采样对齐”；不能把未采样显示成 0 |

底部读数在双图时预留稳定的两行：第一行 A/B 原值，第二行 Δ 与高位深／不可比说明；全宽优先，不能把必要通道信息提前压成“详情”。仅在空间确实不足时采用现有窄窗详情浮层，并显示“当前来源／读数是否有效”的摘要。

图片进入编辑时，需要明示编辑 A 还是 B。既有编辑会话如何选择来源以当前接线为准；UI 可以通过菜单列出可选来源，但不能默认编辑正在显示的差异图。

## 7. 图片编辑：用左右分工替代不断增长的顶部工具排

推荐采用 **左侧 64 宽工具栏 + 中间工作副本 + 右侧 288 宽参数面板**。文件列表暂时让位于工具栏，结束编辑后恢复原先的列表开关。编辑仍发生在所属图片任务中，不额外创建编辑任务或图层项目。

顶部只保留：`返回查看　编辑 A/B 的副本　｜ 撤销　重做 ｜ 另存副本…`。如果有未保存修改，任务标签和来源行使用小圆点加文字提示；不能将“返回查看”包装成自动保存或丢弃。

工具栏使用约 48×44 的图标加短文字按钮，分为几组，中间只留间距：

1. 选择、裁剪。
2. 画笔、马赛克。
3. 标注组（箭头／矩形／文字，按钮显示当前所选标注工具）。
4. 更多处理（填充、清除、智能抠图及能力说明）。

“尺寸／画布”和“旋转／翻转”作为整图操作放在右侧参数面板上部的固定操作组。这样工具选择不再与整图变换、输出、模型检测混成一排。宽窗保证这些入口可见，窄窗由明确标注的“参数”入口打开同一面板。

| 当前工具／操作 | 右侧具体内容 | 确认与反馈 |
|---|---|---|
| 选择 | 当前标注类型、位置摘要、删除所选；标注计数 | 删除全部置于独立次级菜单，不能贴在保存主按钮旁 |
| 裁剪 | 自由／1:1／4:3／16:9、宽高、当前选区；使用已存在的比例能力 | 应用裁剪为工具内主动作，取消紧邻；Enter／Esc 保留。画布选区旁只留尺寸提示，避免再复制整套参数面板 |
| 画笔 | 色块与颜色选择、粗细滑块＋数值、不透明度 | 一笔一个撤销步骤；正在绘制时禁止中途整图变换的反馈仍需清楚 |
| 马赛克 | 块大小、选区尺寸 | 明确“应用马赛克”，不能复用显示成“应用裁剪”的标签 |
| 填充／清除 | 操作范围与当前颜色／透明语义 | 清除与纯色填充的含义分开；不新增 AI 补图 |
| 箭头／矩形 | 颜色、线宽、不透明度 | 标注坐标绑定图像，平移缩放时不漂移 |
| 文字 | 文本输入、字号、颜色 | 输入区占右侧面板的可用宽度；输入焦点不得触发媒体快捷键 |
| 缩放图片 | 固定“尺寸…”入口，打开已有尺寸对话框 | 宽高、锁比例、重采样、预设倍率；保留锁定比例下的实时联动 |
| 填充画布 | 固定“画布…”入口，打开已有画布对话框 | 宽高、填充色、透明可用性；保持居中填充及不能缩小画布的限制 |
| 旋转／翻转 | 固定下拉；左右镜像、上下翻转、±90°、180° | 作用于实际副本和标注，不是只旋转观看视图 |
| 智能抠图 | 更多处理中的能力入口；面板内显示是否可用、检测模型、安装需求 | 未就绪时仍能到达能力说明与检测，处理动作禁用；不把“检测模型”常驻在每个工具的参数行 |
| 另存副本 | 右上主按钮；工具参数确认与文件输出分开 | 保留原图不覆盖、PNG/JPEG 实际能力与透明合成限制；失败保留编辑副本 |

智能抠图的当前文档与源码存在差异：台账／D-019 的“按能力显隐”描述与当前 `ImageWorkspace.qml` 的“常驻禁用按钮＋全工具可达检测”不一致。实施时应以当前实际可达能力为基线整理文档；本提案推荐“能力说明始终可达、执行动作按能力启用”，不借改版改变模型打包策略。

底部继续保留视图工具和“编辑副本”身份。当前产品不能把原图 RGBA 当成副本数值，因此不要为了界面完整而填入看似有效的探针；副本采样未接入时明确显示当前支持的坐标和限制。结束编辑恢复此前的比较模式；需要对比修改结果时仍按现有流程另存后打开。

## 8. 视频打开／单视频查看：建立清楚的时间控制中心

- 左侧使用文件与历史栏，保留“当前文件夹／最近打开”和“选择文件夹／刷新”的两行位置关系；文件选择、上一项／下一项与新标签入口保持原有行为。
- 来源行只显示当前文件身份和必要属性。主时间线／参考在单视频下可以低强调，但不能把它们的不同职责混成一个无法解释的装饰标签。
- 命令栏保留“添加视频…”的清楚入口。现有比较模式禁用时保留“需要至少两个视频”的说明，不用纯灰按钮代替解释；视觉减重后它们不占主动作地位。
- 画面下沿统一放缩放、适应、框选、重置、采样与网格；去掉现在分散在画面角落的重复操作排。
- 时间轴与播放控制在同一停靠区。**默认停靠是推荐，尚未视为用户已经逐项批准；现有停靠／自动浮动／隐藏选择保留，不能因这次重排强制所有用户换模式。**

时间控制区的排布：

| 层 | 左 | 中 | 右 |
|---|---|---|---|
| 时间与定位 | 当前时间码、当前帧 | 时间轴跨可用宽度；缩放后保留全片位置条 | 总时长／总帧数 |
| 播放操作 | 当前播放速度 | 前后定位、前一帧、播放／暂停、后一帧；主要播放键居中 | 长按逐帧倍率；流畅优先／逐帧完整 |
| 区间次行 | 入点 I、出点 O、区间摘要 | 播放区间、循环、往返 | 清除、导出区间 |
| 按需展开层 | 相邻帧开关 | 前后帧条、指标时间线等已有能力 | 关闭展开层 |

首／末帧、前后跳秒、按当前快捷键方案的多帧跳转都保留可达入口；首轮只调整分组和间距，不擅自删掉看似重复的传输按钮。播放速度与长按逐帧速度要有不同标签，不能用一个“1×”代替两种状态。

未载入协议时，协议导入放在更多／检查器中；载入后显示当前协议摘要与上／下生成帧、样本导出等已有入口。协议能力不因存在按钮就变成自动识别生成帧，仍遵循原有数据来源。

实际播放状态保留在底部摘要；发生追赶／跳过等情况才提升强调。相邻帧和时间轴缩略图不得被界面方案描述为任意位置即时可用，沿用已有缓存／采样边界。

## 9. 视频对比：先看清对象，再选择观察方法

推荐命令栏形成三个明确组：

`添加素材　｜ 并排　分割线　局部联动　差异 ▾ ｜ A↔B　A↔C　B↔C ｜ 输出　检查器`

两源只显示唯一比较对；三源显示三个互斥按钮；单源不显示。按 D-023，窄窗也不把比较对塞进更多菜单。比较模式与比较对象都应一步可见，两组之间保留明确间距。

来源行呈现：`A 文件名 [主时间线] [参考]　B 文件名　C 文件名`。主时间线控制时间位置与区间导出源；参考源影响 GT 相关观察；当前比较对决定两路观察对象。三者不合并、不靠同一个蓝色高亮表达。

| 功能 | 具体位置 | 保留的行为与信息 |
|---|---|---|
| 两路并排 | 中央两个等宽画布；小来源标题位于各画布上缘 | 当前比较对决定画面，切对不重置时间、缩放、平移和其他观察状态 |
| 分割线 | 一个共享画布，只有分割手柄进入内容 | 方向／位置在短参数区；左右／上下与 W 键保持一致 |
| 局部联动 | 中央上部总览，下部 ROI 放大窗 | 下方继续沿用 28%–40% 高度范围与最小高度约束；总览框选不转成在局部窗里重新解释坐标 |
| 差异／高亮 | 模式菜单选择显示口径 | 当前类型及按住看 GT 原图在主界面可见；阈值、增益、度量、指标进右侧“对比”页 |
| 三联／参考聚焦／双参考差异 | “布局”菜单保留；可在更多组内明确命名 | 它们是全组视图；点比较对按 D-023 回到上次两路模式，不改 C 键原义 |
| 看 A/B/C、固定参考切候选 | 来源操作及现有明确入口 | 必须保留当前直看／锁定提示；选对与直看退出规则沿用已有决策，不用视觉重排偷偷改变 |
| 对齐／偏移 | 右侧检查器“对比”页的独立分组 | 底部或来源行只显示摘要和当前不可精确对应提示；详细帧号、PTS、偏移在面板中对齐成表 |
| 复制对比图／另存为 | 宽窗命令栏右侧；窄窗“输出”菜单 | 明确输出的是当前显示结果，按 D-018 保持纯净画面；不含新工具条、来源标题、通知 |
| 像素／指标 | 原有探针与右侧指标表 | 不把 Y/Cb/Cr 与图片 RGBA 统一成错误的单一数值语义；未完成采样显示等待 |
| 问题记录／恢复 | 检查器中的观察记录入口或任务更多菜单 | 保留素材身份、模式、位置、限制与恢复失败反馈 |

检查器先沿用当前“对比／播放／信息”三页，调整内部组与阅读顺序，不再创造一排新的顶层页。图片检查器可以复用面板外观，但拥有图片自己的观察／信息内容与能力适配，不能直接复用视频数据模型。

## 10. 窄窗、DPI、面板竞争与浮层

当前产品最低窗口约 960×640，紧凑高度阈值为 680。本轮继续围绕桌面范围设计，不把前轮小样在手机宽度下的重排当作产品移动端承诺。

1. **按实际剩余画布宽度判断面板能否停靠。** 沿用 `LayoutMetrics.availableCanvasWidth` 与 600 逻辑像素画布宽度保护。1440 下文件栏 232＋检查器 288通常可并存；960 下两者同时停靠会挤坏画布，应临时抽屉化／抑制其中一个，不能缩字体硬塞。用户可见开关状态仍保留，扩大窗口后恢复。
2. **图片编辑优先保证工具与画布。** 左工具栏 64 保留；右参数区在停靠后不足画布保护宽度时改抽屉。工具名、当前工具摘要、应用／取消仍可从命令栏或固定短参数行到达；不要求用户每次打开抽屉才能提交裁剪。
3. **紧凑档先收低频动作，最后才缩文件名。** 复制／另存、详细元信息、非活动参数先进入有名字的菜单；模式选择、A/B/C 比较对、播放／逐帧、入出点、保存副本、必要失败状态不能无声消失。文件名省略仍保留槽位与完整名称提示。
4. **参数有固定容器。** 编辑参数在右侧，比较模式的短参数在固定带；不因某个工具增加一个滑块就在顶部再长出一行。复杂面板内部可纵向滚动，确认与保存动作保留可达。
5. **附加时间线内容有明确展开态。** 相邻帧、指标曲线和协议层只在启用时占空间。短窗口同时启用多项时优先保持主时间轴、播放、当前帧与必要区间操作；已有能力在检查器或可展开容器内继续可达。
6. **浮动控制仅在浮动观看模式使用。** 指针在任一子控件上时不淡出；不能遮挡视图条、关键状态或当前选区确认。所有浮层先计算实际画布与其他浮层的避让。
7. **D-020 的图片窄窗读数详情先保留。** 仍用根级、显式开关的临时浮层，不由本提案自动改成新的永久停靠行。将来若统一进图片检查器，必须单独记录对这个临时决定的替代，并重新验证“不跳画布”和遮挡关系。
8. **DPI 使用逻辑尺寸。** 100%／125%／150%／200% 都检查文字、按钮命中区、焦点与图像像素映射；不能把把整窗截图缩小后“看起来能放下”当成高 DPI 通过。

弹窗沿用原生文件选择与保存；自定义尺寸／画布／导出框统一表单栅格、内边距、按钮顺序与焦点。紧凑窗按可用高度限制，内容可滚动；不强制固定大尺寸导致按钮落到屏外。输出错误在对应弹窗持续可读，成功短通知不覆盖正在检查的画面区域。

## 11. 不能在整理界面时丢掉的行为

| 契约 | 改版检查点 |
|---|---|
| 任务身份与恢复（D-022/D-024） | 任务标签不是素材标签；切换、重复打开、未保存编辑、后台不解码的规则不因重排改变 |
| 比较对（D-023） | 三按钮常驻、候选互比可达、切对不 seek、不改 GT、不丢观察状态 |
| 原图与编辑副本 | 保存不覆盖原图；编辑内容不进入原图差异统计；未保存离开／关闭规则完整 |
| 颜色与数值 | 显示转换不改采样／统计／复制；Alpha 过滤不改原值；编辑态不冒充已有副本采样 |
| 原图临时直看 | 按住与锁定状态可辨认，松开恢复；不能将按住控件改成一次性菜单动作 |
| 像素映射／选择几何 | 100% 定义、DPR、ROI、裁剪、旋转、网格门槛与选区换算保持 |
| 时间控制 | 倍率、长按逐帧、焦点、区间闭区间、循环／往返、浮层计时不因新容器失效 |
| 输出 | 对比图仍纯净；片段仍取时间线主源、保持关键帧前滚／B 帧尾部限制；不新增重新编码能力 |
| 异步与失败 | 不隐藏未完成／未知；不发布迟到数据；加载失败保留上一提交结果；无全屏同步阻塞 |
| 能力可用性 | 智能抠图、格式、编码器等按实际能力说明；隐藏执行按钮时仍保留可达的解释路径 |

适用视觉场景包括单图/透明图、图片对比各模式、尺寸不同、编辑参数与未保存状态、
