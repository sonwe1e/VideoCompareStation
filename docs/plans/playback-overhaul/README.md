# 旧播放整改计划的阅读入口

2026-09-22 更新：本目录的 [原始总计划](00_README.md) 与审查报告以 `d04339c` 为主要基线。
原始正文和完整性清单保留用于追溯，不能直接当作当前 main 的缺陷、待办或全部产品要求。

当前工作先读 [Agent 快速定位指南](../../agent-guide.md)、
[产品目标](../../product/visual-review.md) 和 [问题台账](../../engineering/visual-review-backlog.md)。
这些入口区分已提交行为、未提交实现、能力缺口和未验证风险。

| 旧计划中的判断／建议 | 当前如何使用 |
|---|---|
| Reference 与时间线主源耦合、Pair 随槽位泄漏 | 已有分离与媒体身份重映射，先查 ADR 0004 和回归测试，勿重复实现 |
| 后退每步 Exact seek、范围循环只有 QML | 已有反向 GOP 窗口及内核范围循环，按新实现和性能证据核查 |
| 播放追赶策略隐含 | 已有显式策略；状态栏接线和统计含义另见当前 V-01/V-02 |
| 对比指标缺失 | RGB CPU 公式基础已加入，产品端到端链仍未完成，见 ADR 0005 与 V-07 |
| 音频、字幕或更广的播放器扩展 | 当前用户明确不需要，不因旧计划提及就加入实施范围 |
| 继续扩到 N 路 | 当前明确需求是 GT＋两个 Prediction；不要直接扩大资源和渲染上限 |
| 旧计划的优先级、行号、阶段完成状态 | 是当时快照；当前以用户需求、问题台账、实际代码与针对当前版本的验证更新 |

旧文档中的 FrameSet 原子性、异步身份、线程和缓存边界仍有参考价值；
实现约束以根目录 AGENTS、现行依赖规则、ADR 和测试门禁为准。
本入口不修改原始归档及其 SHA-256 清单。
