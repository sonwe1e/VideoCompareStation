# 09｜回归、边界与组合测试矩阵

## 核心结论

Toy 的回归测试不能只按“功能页面”组织。播放器错误通常发生在多个维度的交叉点：例如三路源、VFR、Reference 切换、播放中、设备丢失、200% DPI。完整笛卡尔积不可执行，因此推荐采用四层策略：

```text
不可变式/模型测试
+ 关键维度 Pairwise 组合
+ 历史 Bug 精确回归
+ 真实硬件与长时 Soak
```

任何新功能都必须先标出它改变了哪些维度，再从本矩阵生成最小覆盖集合。

## 二、不可变式测试

这些测试比具体 UI 输出更稳定，应尽量采用 property/model-based 方式。

### I-01 完整 FrameSet

对任何提交的 canonical frame：

```text
presented source set == expected active presentation set
```

Missing 也必须是显式槽位状态。不得只发布部分可用源。

### I-02 ACK 后提交

```text
Snapshot.displayedFrame changes
⇒ matching FrameSetPresented ACK occurred earlier
```

重复/迟到/错误 generation ACK 不得提交。

### I-03 单调性/连续性

- Forward Step：严格 `+1`；
- Reverse Step：严格 `-1`；
- ReviewEveryFrame：严格连续；
- RealTime：单调不回退，跳过的是完整 FrameSet；
- Exact Seek：只保证最终目标。

### I-04 Exactly-once Command Terminal

每个 Accepted Command：

```text
terminal count == 1
terminal ∈ {Succeeded, Canceled, Failed, Closed}
```

Busy/Closed-before-accept 走提交返回值，不再出现异步第二终态。

### I-05 Stale Isolation

任何 revision 或 generation 旧于 authoritative state 的结果：

```text
may retire resources
must not change visible/session state
```

### I-06 有界资源

在任意输入序列中：

- queue size ≤ capacity；
- cache bytes ≤ budget；
- pending timers ≤ bounded active transactions；
- thread count 不随命令数量增长；
- marker model 不随全片帧数创建无限 QML item。

### I-07 回滚

拓扑/Reference/Timeline Master/Pair transaction 失败：

```text
old Ready session remains usable
displayed frame remains last ACKed
```

### I-08 身份稳定

source reorder/slot remap 后：

- SourceKey 不变；
- Pair 仍指向同一文件身份；
- analysis cache 不错配；
- UI alias/role 不串路。

### I-09 Comparison Provenance

每个 metric/export：

```text
result identity == pair + source fingerprints + revisions + domain + metric version + ROI/range
```

任一要素变化，旧结果不得伪装为当前结果。

### I-10 UI 非权威

随机化 QML signal 延迟/丢失时，内核仍不能：

- 越过 range；
- 提交 stale frame；
- 失去 command terminal；
- 改变 canonical mapping。

## 四、核心功能矩阵

### 4.1 Open/Close

|---|---|

## 十一、发布前必过场景

无论本次改动大小，最终发布必须覆盖：

1. 单源播放/逐帧/seek；
2. 两路 Side/Wipe/Diff；
3. 三路 Pair 全组合；
4. Reference/Timeline Master/Pair 切换；
5. CFR/VFR/B-frame；
6. D3D11VA 与软件回退；
7. held forward/backward；
8. Range；
9. Scrub；
10. device loss/shutdown；
11. 100/150/200% DPI；
12. package install/upgrade；
13. source changed-on-disk；
14. error recovery；
15. exact release SHA performance。

这份矩阵的使用原则是：**先用不变量覆盖无限状态，再用组合矩阵覆盖交叉风险，最后用历史回归和真实硬件捕捉模型之外的问题。**
