# 视觉质量审查：产品目标与工作流

更新：2026-10-25。本页维护产品范围与应保留的行为；实现和验收缺口见
[问题台账](../engineering/visual-review-backlog.md)，产品取舍见
[决策登记册](../engineering/decision-register.md)，格式边界见 [媒体支持](../media-support.md)。
已实现不等于真实硬件或所有显示环境均已验收。

## 1. 产品范围

CompareStation 是 Windows 本地、静音的视觉质量审查工具，面向视频播放、视频对比、
图片查看、图片对比及轻编辑。重点是观察模糊、重影、掉帧、插帧形变、运动不流畅和透明边缘。
用户计划免费、非营利地维护它；不扩展音频、字幕、媒体库、项目文件或完整视频编辑器。

| 工作流 | 必须支持的观察与操作 |
|---|---|
| 视频播放 | 定位、前后逐帧、长按连续逐帧、倍速、区间与循环；超出解码能力时如实显示状态 |
| 视频对比 | 两个 Prediction 或 GT＋最多两个候选；并排、分割线、差异/高亮、局部放大与同区域切换 |
| 图片查看 | 常见图片与 PNM 家族；查看通道、RGBA/Alpha、真实尺寸、透明背景与目录连续翻页 |
| 图片对比 | 维持双图；并排、分割线、单图 A/B、淡化、RGB/Alpha 差异；坐标和观察位置联动 |
| 图片轻编辑 | 原图不变，编辑副本、撤销/重做、另存；不引入图层系统或内容感知修补 |

常用素材基线为 1080p 8-bit、PNG/JPG；倒退优化以单视频为主要场景。
这不是拒绝其他已有支持格式的理由，也不是 4K/高位深性能承诺。
“PPNM”按 PNM 家族记录，特殊变种需真实样例确认。

## 2. 打开、任务与文件夹

- 首屏与文件菜单统一为“打开文件…”（`Ctrl+O`）、“打开文件夹…”和“对比文件夹…”。
  视频与图片混选明确报错；一次打开最多三路视频或两张图片，不静默丢弃多余文件。
- 一个标签代表一次审查任务：单视频/两到三路视频，或单图/一对 A/B。默认打开新标签，
  重复任务聚焦已有标签。同名素材用父目录消歧。视频、图片标签上限各为 12。
  `Ctrl+W` 关闭当前任务，`Ctrl+Tab` / `Ctrl+Shift+Tab` 切换，标签不跨重启保存。
- 视频后台标签只保存观察状态，不解码、不分析；切回恢复后保持暂停。
  同一素材组＋参考源身份相同才是同一视频任务，AB 与 AC 不合并。
  对齐分析结果和手动锚点不随标签保存；细节见 [视频标签契约](../plans/video-task-tabs-design.md)。
- 图片标签各自保留配对、模式和视口，总工作集沿用 1.5 GiB 硬顶。当前只有一个编辑会话，
  按素材路径归属标签：允许带着未保存修改切走，关闭所属标签或在别的标签开始编辑时应拒绝并解释。
- 文件侧栏显示顶层目录、自然排序与共享最近历史；不递归扫描、不做 EOF 自动连播。
  单视频活动时在当前标签换片，比较任务活动时打开另一个单视频标签；“在新标签打开”明确新建。
  成功打开后才推进选中项或播放，失败保留上一已提交画面。图片有上一张/下一张。
- “加入当前视频对比”只扩展当前 1–2 路任务；满三路、重复或不可读文件说明禁用原因。
  改变源组前确认顺序与参考源；取消或过期确认不能改另一任务。
- 来源标签右键关闭素材只移除会话成员，不删磁盘文件。操作绑定稳定素材身份，
  同名或菜单打开后发生替换不能误关。图片关闭 A 可将 B 提升为主图；视频移除后保持合法角色。
  最后一个素材关闭后按任务路由进入相邻任务或空态。

## 3. 观察结果的含义

- 素材重复帧、播放器跳过完整帧组、呈现 ACK 间隙与物理显示刷新是不同统计，不能相加。
  未检测显示未知，不能写成零缺陷。掉帧以整组比较帧计，不能拆源掩盖不同步。
- 流畅优先与逐帧完整是明确的两种代价；默认 Contextual 当前解析为流畅优先。
  解码跟不上时，不承诺原速、每帧完整与低延迟同时成立；所选倍率不代表实际倍率。
- 时间线主源、GT 参考源和当前比较对是独立角色。默认严格索引不自动补帧/插值；
  按时间/人工锚点依据明确映射，未知或缺帧不能宣称精确对应。
- 视频读数是规范化平面值，转换标记须说明位深、范围、色度或重采样。
  视频指标使用解码转换后的全帧 RGBA8 RGB；10-bit 输入也先降到 8-bit，Alpha 不混入 RGB MAE/MSE。
  视口 ROI、显示增益与缩放不改变该统计，CPU 坏点数不保证等于屏幕高亮像素数。
- 图片探针/统计基于解码缓冲；RGBA64 sidecar 标明“转换后 RGBA16”，不能冒充文件原始平面。
  支持范围内可解析 ICC 的 SDR 图片默认转 sRGB 显示；开关只改显示派生结果，
  不改探针、差异、Alpha 统计、编辑源或导出码值。Windows 输出与物理显示仍标“显示环境未验证”。
- 视频 100% 对应物理像素（含 DPR/SAR 约束），不可达时解释；图片区分真实尺寸与适应窗口。
  原图像素网格默认关闭，仅最近邻且实际物理放大达到 800% 时显示；视频差异及额外 ROI 小窗不画网格。

## 4. 比较、定位与透明度

视频比较对 A↔B/A↔C/B↔C 是常驻互斥入口，紧凑档仍保留；两源只显示唯一一对，单源隐藏。
显式选对在三联/参考聚焦/双参考差异/局部联动下回到上次两路模式（首次并排）。
`C` 保持固定 GT 切候选，不改视图。换对保留播放位置、倍率、视口、ROI、差异参数与区间，
读数随新对刷新，未完成显示等待。模式切换退出临时直看；单独选对保留已有直看语义。

并排/分割线/差异观察共用缩放和平移。Shift+拖动框选放大；视频 Alt+拖动设 ROI，
局部联动用总览原图坐标重选，下方窗口观察同一区域。分割线 `W` 换方向，Alt+相应方向键微调。
按住或锁定看 GT 时明确标示来源，解除后恢复原模式，不改变时间线或比较对。
三源默认布局仍需用户任务验证，不能把设计推荐当成确认。

`I`/`O` 设置含端点区间，循环与往返分别可控；暂停后继续保留方向，往返端点不连续重复。
入点/出点保持可达，时间轴放大后用位置条表示当前窗口在全片的位置。

图片“单图 A/B”明确显示当前 A 或 B，点击/空格切换须与拖动区分；淡化有显式入口和滑杆。
对调不改配对身份，单侧替换失败保留原侧。差异增益只改显示，不重算原始统计。

透明度观察包含中性棋盘格、深色/黑/白背景、Alpha 灰度、Alpha 差异和忽略 Alpha 的 RGB。
透明像素里的隐藏 RGB 不归零，直通/预乘语义必须说明。背景现为带当前值的选择器。
Alpha 阈值过滤默认关闭，仅在忽略透明 RGB 视图中按严格 `A > T` 生效；隐藏区呈中性棋盘格，
探针继续读原值并说明被隐藏。开过滤时自动进入可应用的原图视图，不修改素材或统计。

读数区提供整数/归一化切换与 RGB/RGBA/Hex 复制。8-bit 除以255、转换后16-bit 除以65535，
Δ 保持符号，Hex 不变。复制的是当前素材代次最后有效样本，旁边说明源与坐标；
素材代次变化使旧样本失效。鼠标离开画布可保留读数，十字线应隐藏，普通悬停不挤动画布。

## 5. 图片轻编辑

现有工具包括裁剪、镜像/翻转、90°/180°旋转、缩放、居中填充画布、画笔、马赛克、
选区填充/清除、箭头/矩形/文字标注。任意角度旋转、图层、批量处理和内容感知补图不在当前范围。
智能抠图按本机能力显隐，发布包不含模型和 ONNX Runtime；异步化与质量验收仍见 S03。

- 编辑从已提交解码缓冲派生，拒绝保存到源路径。查看派生图永不作为编辑源。
- 撤销/重做有步数与字节预算；一笔、一次拖动或整图操作各算一步，不保存项目文件。
  画笔、马赛克、填充/清除使用脏矩形补丁；标注为最多64个的平面对象列表。
- 选区、笔画与标注使用图像坐标；连续裁剪以当前副本为输入。几何变换同步标注，
  裁剪丢弃保留区外标注；镜像/90°旋转不重采样，未结束手势期间拒绝变换。
- 缩放默认锁定比例、可选平滑/像素级插值；居中扩画布拒绝更小尺寸，尺寸不变不入历史。
  填充颜色包括黑/白/中灰/透明，透明填充要求有 Alpha。
- 编辑态只显示工作副本，顶部编辑带说明来源；参数在右侧面板/抽屉，应用与取消始终可达。
  「返回查看」恢复比较模式并保留副本及撤销历史；「继续编辑」复用会话，只有明确放弃修改才丢弃。
  未保存的后台任务关闭与窗口退出均提供切回保存、放弃修改和取消入口。
- 「与原图比较」建立临时快照标签：A 为编辑源原图，B 为当前编辑结果（含标注）。
  后续编辑/撤销不改变已有快照，同一版本复用标签，新版本独立。快照复用比较模式与差异管线，
  标注作为 B 的扁平像素参与该快照统计；原任务的差异统计仍只针对原图。
  快照是 RGBA8 编辑缓冲，不声明原文件位深或 ICC 精度；计入既有 12 标签/1.5 GiB 上限。
  快照不支持换图、作为新的编辑源或直接写入可恢复问题记录；先另存为文件再打开可做持久记录。
- 查看态拖动平移，编辑态左键执行工具，中键平移、Shift+拖动放大；
  单图/编辑态坐标跟随当前副本，不能把原图读数套到变换后的副本上。
- 维护 PNG/JPEG 两种保存路径；JPEG 显式合成背景，若当前包缺编码能力须明确提示，不能假装保存成功。
  不新增 16-bit PNG 或 Deflate TIFF 保存（D-015）。

## 6. 问题记录与输出

问题记录绑定素材身份与观察状态。图片恢复会重开素材并恢复模式、通道、背景、视口、分割线、
差异增益、重采样和 Alpha 过滤；旧字段缺失显示部分恢复，失败/超时保留已提交素材。
附近帧诊断与生成帧导航依据显式插帧协议，不凭奇偶猜测来源。便携问题包和批处理仍属后续能力。

| 输出 | 必须解释的边界 |
|---|---|
| 复制/另存对比图 | 纯净显示画面，排除来源牌、徽章、横幅、控制条与 letterbox；不是源文件码值。PNG `Description` 保存来源/观察信息及显示口径声明，剪贴板不带元数据 |
| 区间流拷贝 | 不重编码，只导出规范源的视频；起点回退到可用关键帧，结束受容器/编码依赖影响。报告请求与实际边界，不承诺任意入点精确成帧；无音频/字幕 |
| 精确 PNG 样本 | 解码像素及 manifest，记录每个成员的来源、帧号和转换口径；不是原始压缩码流 |

导出可取消，失败不留下可消费的半成品；先写临时输出、读回验证后事务发布，失败不覆盖既有结果。
显示截图、解码样本和流拷贝三者不能统称原始无损输出。

## 7. 界面与后续选择

沿用中性深灰、克制强调、画面优先和统一控件状态。任务标签、素材来源、操作、参数和读数
各有明确位置；五类工作区布局见 [设计约定](../plans/ui-workspace-redesign-2026-10-24.md)。
适应、100%、重置、常用比较入口可见且可用键盘到达；窄窗通过折叠/抽屉保持可达，
不能用重叠或缩小必读文字掩盖空间不足。错误、来源、焦点与观察口径始终可辨。

HDR/完整高位深、三源默认画幅、SAM2 内置方式及新的生成帧规则按真实任务分别决定。
区域指标、区间报告、盲比、三文件夹或图片序列扩展是候选，不因底层类型已存在就宣称可用。
未解决条件保留在台账和决策册，局部修复不以完成整个长期路线为前置。
