# 版本号与代码提交

CompareStation 使用 `主版本.次版本.修订号`。版本号写在仓库根目录的
`CMakeLists.txt`；Windows 程序文件信息、ZIP 文件名和发布校验都从这里读取。
窗口标题也显示当前构建版本。

- 每次代码提交保留独立的 Git SHA，并用 Conventional Commits 描述改动；不为每次提交递增产品版本。
- 有用户可见的新能力或工作流变化时递增次版本；兼容修复递增修订号；不兼容变化才递增主版本。
- 准备发布时，给待验收提交打与 CMake 版本一致的 `vX.Y.Z` 标签。
  标签触发测试、打包、硬件门禁和草稿发布工作流；完成验收后才对外发布。
  开发中的版本号不代表已经发布。

`v2.0.2` 于 2026-09-29 发布。`v2.0.3` 保留为原有兼容修复草稿，不移动其标签。
当前版本 `2.1.0` 新增视频文件夹播放工作流，并包含指标窗口顺序调度与阈值无关分析复用。
本次发布经维护者授权：不执行本地硬件长测；GitHub Windows 自托管 runner 离线时直接发布，
未执行项在 [2.1.0 发布说明](releases/v2.1.0.md) 中列出，不记作通过。现有 CI 与硬件门禁定义保留。
发布门禁要求
候选提交与 `origin/main` 完全一致（`tools/release/verify-release-commit.ps1`），因此标签只能打在
已合并的 main 提交上。
