VCStation C — Hybrid Adaptive Implementation Plan

Baseline: sonwe1e/Toy dev @ e4f61e5acfd362e991086149e5217e4a5ed6243b

Product contract

Single source

Player-first.

Canvas is full-bleed.

Contextual transport resolves to auto-hide overlay.

A persisted Pinned preference means docked transport, never an overlay.

Source filename appears only with the transport / lightweight HUD.

Two or three sources

Review-first.

Contextual transport resolves to pinned docked transport.

Reviewed pixels are never covered by a pinned control.

Source strip + compare bar remain fixed review chrome.

Inspector remains docked on wide windows and drawer-style on narrow windows.

Transport semantics

Pinned = docked outside reviewed pixels.

Auto hide = overlay over canvas.

Hidden = no transport.

Contextual = Single → Auto hide; Multi → Pinned/Docked.

2. Split interactive-step cancellation and failure

File

src/application/src/PlaybackCoordinator.cpp

Replace the one-size-fits-all:

stopInteractiveStepRun(error)

with two semantics:

enum class InteractiveStepStopReason {
    NavigationSuperseded,
    PlaybackStarted,
    SessionChanged,
    DeviceChanged,
    Shutdown,
};

void cancelInteractiveStepRun(InteractiveStepStopReason reason);

void failInteractiveStepRun(domain::MediaError error);

Cancellation

Used for:

Previous / negative step

random Seek

First / Last

Play

source topology/reference/alignment revision change

normal shutdown

Rules:

cancel current/prepared provider requests;

increment playback generation;

complete outstanding step commands as Canceled/Closed;

do not set lastError.

Failure

Used for:

provider RequestFailed;

render publish closed/failure;

presentation timeout;

malformed/mismatched FrameSet;

unrecoverable graphics/media failure.

Rules:

preserve last fully ACKed displayedFrame;

stop current/prepared requests;

increment generation;

set state_.lastError;

fail the owning command(s);

publish immediately.

Tests

real provider failure surfaces snapshot error;

superseding with Previous does not surface error;

timeout surfaces error;

rendered-but-not-provider-terminal frame never loses its command terminal;

prepared-frame failure/rejection cannot strand framePending.

Add a transport command or state:

struct SetPlaybackRangeCommand {
    CommandContext context;
    std::optional<FrameRange> range;

};

PlaybackRun owns:

std::optional<FrameRange> range;
bool loop;

At Out:

do not emit QML seekFrame(In);

prepare or retain a bounded start-of-range successor;

commit Out;

re-anchor playback at In;

continue.

Correctness:

never present outside [In, Out];

no partial set;

stable behavior for VFR timeline;

disabling loop mid-flight settles current ACK and continues normal playback;

source/reference/alignment changes clear/remap range through MediaTime.

First implementation batch

Recommended actual first patch:

Do not combine native loop or thumbnail provider into this first patch.

it delivers an immediately visible C-layout improvement;

failures are easy to bisect.

After this patch is green, implement timeline affordances + status rail, then native range loop, then thumbnails/alignment workflow.
