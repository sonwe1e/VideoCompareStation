# CompareStation 2.1.0

本次新增本地视频文件夹播放，并让视频差异分析更适合反复观察。仍是 Windows x64 的
静音视频／图片查看与比较工具，不增加音频、字幕、媒体库或项目文件。

## 新增与修复

### 从文件夹选视频并播放

- 首屏、文件菜单「从文件夹选视频…」或 `Ctrl+Alt+O` 选择本地目录。
- 顶层 `.mp4/.mkv/.mov/.avi/.m4v` 按文件名自然排序，支持中文路径。
- 点击文件，打开成功后播放；提供手动上一项／下一项，不在 EOF 自动连播。
- 播放中换项先异步暂停，等传输与旧帧收尾再打开，修复「无法提交视频打开请求」。
- 当前高亮跟随实际已提交源；失败不认领错误文件，快速换选／取消不会误自动播放旧请求。
- 目录枚举在后台且有界；列表可收起，纯净模式隐藏。目录选择本身不替换当前画面。

不递归扫描、不生成缩略图、不监视目录，也不接受显式 UNC／网络 URL。
扩展名过滤不代表文件一定可解码。取消不会强行终止已交给内核的活动 Open，后者可能完成
为暂停的视频。文件数量上限为 100,000，超限报错而不发布截断列表。

### 视频指标少做重复工作

- 当前观察帧优先发布，其余窗口按连续顺序解码，减少交替 seek／前滚。
- RGB 基础分析和三种像素差异口径的分布只计算一次；已有分析切换阈值／口径无需重新解码。
- 保留独立 CPU 标量参考、完整异步身份检查和有界样本缓存。

首次完整分析仍有成本；复用仅限当前会话已分析样本。未采样、已淘汰或真实比较输入变化时
仍需计算，不是整部视频永久缓存。指标用于定位差异，不自动判定哪个版本画质更好。

### 正常打开与升级

- 图片工作区接收普通文件／Explorer 视频请求时，等真实 Open 成功后切换到视频工作区；
  打开等待期间仍可产生首帧呈现 ACK，失败保留图片任务。
- 包含 2.0.3 草稿中的右键升级去重、按当前注册目录启动及逐帧空闲间隙游标复用修复。
- ZIP 只包含必要运行时、资源、许可证和用户入口。保留 app-local CRT／UCRT DLL，
  不附带重复运行库安装器、未使用的图形编译器或开发符号。

## 下载与升级

- `CompareStation-2.1.0-windows-x64.zip`：唯一软件包，解压后运行 `CompareStation.exe`。
- `SHA256SUMS.txt`：ZIP 的 SHA-256 校验值。
- 升级前关闭旧应用，解压到独立的新目录并启动新版一次，使当前用户右键入口更新到新目录。
  本版本 shell DLL 为 `CompareStationShell-2.1.dll`；不要只替换旧目录里的 EXE。
- 此版本为**未签名**构建；SHA-256 校验完整性，不证明发布者身份。
- 2.0.3 的既有标签和草稿未移动，也未将其旧 ZIP 冒充本次构建。
