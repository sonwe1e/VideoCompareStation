# VCStation 1.6.0

VCStation 1.6.0 是一次以交互正确性、性能可观测性和混合自适应布局为重点的版本。
它在 v1.5 交互式前向步进流的基础上，拆分了取消与失败语义、加入了持续前向性能门禁，
并让 transport 布局随源数量与 Pinned 偏好自适应切换。

---

## 主要变化

### 交互正确性

- 将 `stopInteractiveStepRun(error)` 拆分为两个语义路径：`cancelInteractiveStepRun(reason)`
  （导航取代、播放、关闭等正常取消，不设置 lastError，命令完成为 Canceled/Closed）与
  `failInteractiveStepRun(error)`（provider 失败、渲染关闭、呈现超时、帧集不匹配等硬故障，
  设置 lastError，命令完成为 Failed）。重分类了全部 10 个调用点。
- 左右方向键在**所有**快捷键预设下统一为 ±1 帧步进。此前 Player 预设（preset 1）将左右映射为
  `stepSeconds(5)`，在 30 fps 源上会一次跳动约 150 帧，违背了「左右方向键逐帧」的预期。
  Player 预设仍保留 Ctrl+左右（stepSeconds(30)）和专用五帧/秒按钮作为大幅跳转。

### 性能可观测性（plan M1.1）

- 新增持续前向步进性能门禁：在 Main.cpp 的 HeldStepping 阶段以 25–35 Hz 节拍连续提交
  300 次 +1 步进，记录每帧延迟与序列正确性。
- 新增 9 项指标：held_step_p50/p99、held_step_presented_frames、held_step_sequence_errors、
  held_step_generation_delta、held_step_exact_seek_delta、held_step_sequential_request_count、
  held_step_cancel_count、held_step_decoder_reopen_count。
- 配套 provider 统计计数器（sequentialRequestCount、cancelCount、decoderReopenCount、
  generationDeltaCount）与 run-performance-gate.ps1 门禁。
- 门禁硬指标：0 missing intermediate FrameIds、0 stale commits、0 decoder reopen；
  顺序续读比与 P95 延迟为记录指标 + 软警告（尚无基线）。

### 混合自适应布局（plan M2.3 / M2.4）

- Transport 布局随上下文自适应：单源 → 自动隐藏覆盖层（overlay），多源 → 固定停靠（docked）；
  Pinned 偏好持久化为停靠态。停靠时 viewport 底部预留 transport 高度，已评审像素不曾被遮挡。
- PlayerOsc 增加 `docked` 与 `sourceLabel` 属性：停靠态为不透明面板、无唤醒条、永不淡出；
  覆盖态保留 1200 ms 自动隐藏。高度由内容驱动（时间轴 + 13 px 间隙 + 传输条 + 底部内边距）。
- 单源模式下隐藏 ActiveSourceStrip（不再覆盖画布），文件名显示在 PlayerOsc 读出中；
  添加/打开能力通过菜单栏、拖拽与上下文菜单保留。

### 测试

- 新增 MainQmlContractTests.DockedTransportResolvesContextuallyAndClearsViewport：在单一
  Main.qml 实例上验证多源停靠、单源覆盖、空态隐藏三种上下文几何。
- 新增 PlaybackCoordinatorTests.ProviderFailureSurfacesStepStreamError 与
  SupersedingStepDoesNotSurfaceError，分别验证 provider 失败上抛 lastError 与
  反向步进为正常取消（不设置 lastError）的区分不变量。
- 修复了 SupersedingStepDoesNotSurfaceError 在并行 ctest 下的偶发超时：原测试依赖 5s
  截止时间竞赛，现改为确定性驱动取消后的精确_seek 完成。

## 发布范围

VCStation 支持 H.264、HEVC、MPEG-4 Part 2 与 SDR 视频，不播放音频轨道。发布产物为
Windows x64 ZIP、MSI 与 SHA256SUMS。本版本保持未签名：Windows 可能显示 Unknown
Publisher 或 SmartScreen 提示，SHA-256 仅用于校验产物完整性。

Draft Release 仅会在精确 tag/版本验证、Debug 与 Release 检查、Quality、D3D11VA 硬件和
性能门禁、1.2.0 升级、packaged smoke、shutdown soak，以及 FrameProvider 100 次资源退休
压力测试全部在目标 release SHA 上通过后创建。

---

## 已知限制

- 性能门禁的绝对 P95 阈值需等基线数据积累后才可硬门禁；当前顺序续读比与 P95 为记录 + 软警告。
- 本批次未包含时间轴缩放控件（plan M2.5）、统一状态栏（M2.6）、协调器原生范围循环（M3.7）、
  缩略图泳道（M3.8）与引导式对齐工作流（M3.9）；这些在 M1–M3 稳定后按序实现。

## 维护批次 2026-08-14（发布构建）

在 v1.6.0 基线之上追加的维护与性能批次，随本次发布构建一并交付：

- **播放 trace 诊断（默认关闭）**：有界 MPSC 环形缓冲，生产者 try-lock 永不等待；
  JSONL 文件 sink 经同目录事务在 finalize 时原子发布；`DVS_PLAYBACK_TRACE` 环境变量启用，
  顺序关闭时排空并 fail-closed。门脚本 `tools/testing/run-navigation-gate.ps1` 与
  `run-comparison-semantics-gate.ps1` 现做全文件结构校验（schema v1）。
- **SourceFrameCache O(1) 查找**：LRU 列表配哈希索引，查找/提升/替换/淘汰均摊常数时间，
  含索引 rehash/splice 压力测试。
- **GUI 线程零文件系统调用**：源文件 exists/size/mtime 检查改为代际后台任务
  （250 ms 节流、陈旧代际拒绝、销毁后完成安全），GUI 只读缓存结果。
- **门工具加固**：命令引号实现收敛为单一模块；修复 Windows PowerShell 下快速退出
  子进程退出码丢失问题；性能门增加有界超时与 1080p60 Diff 素材哈希契约。
- **测试与文档**：统一 `dvs::test_support` 临时目录；QML smoke 稳定性修复；
  记录本机构建环境笔记（见 docs/engineering/maintenance-and-performance.md）。
