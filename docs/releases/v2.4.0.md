# CompareStation 2.4.0

本次交付图片轻编辑的整图变换与画布导航，并统一视频观察读数的一致性：新增镜像／
翻转／旋转、单图与裁剪十字线、光标锁定平移和滚轮缩放；视频像素读数改为规范化帧值
并绑定已呈现帧身份，「按住看原图」改为直看会话 GT 源，问题记录恢复改为两阶段事务。
仍是 Windows x64 的静音视频／图片查看与比较工具，最多三个视频源，不解码或播放音频，
不新增字幕或项目文件。

## 新增与修复

- 图片整图变换：编辑栏新增「旋转 / 翻转」菜单，提供水平镜像、垂直翻转、顺／逆时针
  90° 与 180° 旋转。每次操作独占一个撤销步，历史预算计入前后两份缓冲；像素与标注
  一起变换，文字标注保留方向矩阵、变换后仍可选中、移动与删除；未完成的笔画或标注
  拖动期间拒绝变换，与当前方向相同的整圈旋转不产生历史步骤；变换后适应窗口，画面
  身份牌显示副本的当前尺寸。透明通道与 16 位格式保持。任意角度旋转与批量变换不做。
- 单图与裁剪十字线：单图查看、手动 A/B 与编辑画布默认显示十字线和像素坐标，坐标从
  `(0, 0)` 开始、按像素向下取整，与 RGBA 读数一致；悬停在留白或图片范围外时清除。
  缩放、平移、连续裁剪、旋转及撤销后按当前画面重新映射，即使鼠标停住。编辑态底部
  标注「编辑副本 · 像素」，不把不可变原图的 RGBA 值套用到工作副本坐标；双图并排仍按
  归一化位置联动，各侧标签使用自己的像素尺寸。
- 画布导航：光标锁定平移在单图、分割（wipe）与淡入（fade）模式下均按 1:1 跟随指针；
  滚轮缩放按 angleDelta 做平滑指数缩放。裁剪交互重构为静态视口覆盖层，消除拖动抖动
  与递归坐标漂移；选区带 8 个拖拽手柄与整体移动，裁剪进行中可用右键平移画布、双击
  提交；缩放下的裁剪暗幕按上／下／左／右四块不相交分区严格限定在图片矩形内。
- 修复连续裁剪的留白边界缺陷：从留白拖入图片时先钳制两端再计算宽高，旧版把起点
  `(-5,-4)` 到 `(25,18)` 的框记录成起点 `(0,0)`、尺寸 `30×22`（应为 `25×18`），
  留白像素被计入宽高，首次裁剪后尤为明显。
- 视频像素读数一致性：读数面板从「源码值 YCbCr」改为「规范化帧值 YCbCr」，逐源标注
  「已转换」（按来源格式判断）、缓冲位深、来源格式与范围，未知信息明确写未知。探针
  只读取已绘制的 front publication，一次批量锁定一份帧组，A/B/C 必然同帧；结果携带
  请求、帧、会话与播放代际身份，迟到结果按帧丢弃，取消或更换渲染服务后队列里的旧
  交付也被丢弃。播放开始即取消在途查询并冻结已有值，冻结值标注「冻结于第 N 帧」；
  同一整数像素内的小幅移动不追加回读。回读使用固定三槽 1×1 staging 纹理与非阻塞
  轮询，不阻塞 GUI／渲染线程，DeviceBusy 有界重试。
- GT 直看语义：差异模式的「按住看 GT 原图」改为绘制会话参考（GT）源而非比较对第一
  路，与参考焦点主面板同一槽位；GT 槽位不可用时画黑而不是画错帧，无 GT 时快捷键与
  按钮禁用并说明原因。键盘锁定时视口常驻「已锁定直看 GT」及源名称，不再只靠一条会
  消失的 HUD 消息；GT 身份失效（换会话）时自动解除。命中映射使用 GT 自己的长宽比
  与旋转。
- 问题记录恢复事务化：列表点击只经一个执行入口，打开、比较对、seek 都记录命令 ID
  并等待匹配终态，每阶段绑定会话 epoch（包括同 URL 重新打开）；打开或 seek 失败立即
  结束，15 秒无完成回调报告超时，换会话不把记录视图重放到新会话。比较对被拒时如实
  提示「部分恢复」而不是静默装作成功；图片记录的视图状态（模式／缩放／平移）目前
  不重放，恢复时明确提示。
- 修复一处崩溃：源切换导致首快照不一致时，控制器构造路径对空快照解引用即崩溃；现
  以失败关闭处理并带回归。

## 验证

本文件随 v2.4.0 候选提交维护。合入前在 Windows／MSVC／WARP 完成本地验证：dev 预设
全量 1046 项选择，1039 通过、3 skipped、4 disabled，0 失败；最终平台与主窗相关回归
304 项通过、4 disabled，0 失败；图片裁剪／变换轮相关回归 276 项（270 通过、2 skipped、
4 disabled）。三轮受控变异 64/64（一致性轮 23、裁剪与变换 29、十字线 12）全部触发
对应回归失败，源码逐字节恢复；脚本校验每个源码锚点及总检查数。format-check 347 个
文件、C++ lint 与 QML lint（零警告）通过。真实 GPU 上的长期播放性能、真实素材全 App
键鼠走查与发布门禁由标签触发的 CI 执行；本地验证不据此宣称 FPS 或延迟变化。

## 下载与升级

- `CompareStation-2.4.0-windows-x64.zip` 是唯一软件包，解压后运行 `CompareStation.exe`。
- `SHA256SUMS.txt` 提供 ZIP 的 SHA-256 校验值。
- 升级前关闭旧应用，解压到独立的新目录并启动新版一次，使当前用户右键入口指向新目录。
  本版本 shell DLL 为 `CompareStationShell-2.4.dll`，不要只替换旧目录里的 EXE。
- 此版本为未签名构建；SHA-256 校验完整性，不证明发布者身份。
