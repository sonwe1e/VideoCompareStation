# CompareStation 2.0.1

2.0.1 是 2.0.0 的修复版本。查看与对比行为不变，改的是**安装形态**：解压 ZIP 后首次启动即自行
注册资源管理器右键项，取消注册之后也不会被自动加回。2.0.0 的包要求用户自己运行包内脚本，
对不打开终端的用户来说，这一步等于「右键菜单里什么都没有」。

## 主要变化

### 解压即用：应用启动时自行注册

- 每次真实启动时按当前用户注册 `Compare with CompareStation`，覆盖 5 种视频与 13 种图片扩展名，
  不需要管理员权限。选中一个文件打开它，两个视频或两张图片直接进对比，其余选择保持隐藏。
- 只有在自己所在目录里**同时存在** `CompareStation.exe` 与版本推导出的
  `CompareStationShell-<major>.<minor>.dll` 时才写注册表。目录被破坏时会明确报错，而不是写进一个
  Explorer 永远加载不了的路径——那种情况下每次比对都「一致」，自愈就永久失效了。
- 目录移动、注册项被其他工具清理后，启动时比对键值并重写不一致的部分；此前「右键项静默消失」
  正是这种形态。一致时完全不写。

### 取消注册依然有效

`-Uninstall` 会写 `HKCU\Software\CompareStation\ExplorerContextMenu=0`，之后启动不再把入口加回；
重新执行注册脚本写回 `1`。`DVS_DISABLE_SHELL_REGISTRATION=1` 可让某一次启动完全不碰注册表。
手工用 RegEdit 写成文本形式的 `0`/`false`/`no` 同样按「关闭」处理。

### 顺带修掉的三个入口缺陷（2.0.0 也存在）

| 缺陷 | 现象 |
|---|---|
| `RegisterExplorerCommand.ps1 -Uninstall` 在 `Set-StrictMode -Version Latest` 下抛异常 | 只删掉第一个扩展就中断，「可卸载」从未真正成立 |
| 双击入口 `.cmd` 不转发参数 | INSTALL.txt 里那条 `-Uninstall` 反而把命令再注册一次 |
| `pause` 被两条错误守卫（带引号的 `if not exist "con"`、`call )`）变成不可达代码 | 双击后窗口一闪而过，看不到任何提示 |

### 门禁

- 新增两道跑在 `ctest` 里的检查：脚本完整性（每个 `.ps1`/`.psm1` 都能解析，每个 `.cmd`/`.bat` 都是
  纯 ASCII + CRLF）与硬编码机器路径（路径必须从 `$PSScriptRoot` 派生）。工作区改名后
  `tools/testing/` 里 16 处指向旧目录的默认值一并修掉。
- 新增 `tools/release/verify-release-package.ps1`：直接在**打包产物**上校验版本推导的 shell DLL、
  可执行文件里的注册代码、与构建产物的一致性，以及 INSTALL.txt 的卸载说明与逃生开关。
- 修掉长期变红的 `Check coverage gate behavior`：覆盖率门禁新增 `-SourceRoot`，让 fixture 自洽，
  不再因为新增源文件就失败。

## 验证

- dev 与 release 预置各 431/431 目标构建通过；`ctest` 782/782；`format-check` 与 `lint` 均 exit 0。
- 注册行为：13 项 GoogleTest（每条断言都用变异测试证明可判别）、双击入口验收脚本 49 项、
  跨组件契约 16 项（含「卸载后应用拒绝加回」），注册表在运行前后逐键一致。
- 打包形态：`verify-release-package.ps1` 16/16。

## 已知限制

- 未在无头环境实测真实 GUI 首次启动与资源管理器里的实际观感；启动路径的证据是跨组件契约、
  包内二进制检查与真实 COM 服务器组件测试。
- `REG_QWORD`、`REG_BINARY` 与带空格的 `" 0 "` 标记值仍被读作「开启」；随包工具不会写入这些形态。
- 18 个扩展名清单在仓库里仍有四份，没有跨份一致性契约测试。
