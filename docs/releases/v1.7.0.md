# CompareStation 1.7.0（发布说明草稿）

当前是开发版本，尚未创建 `v1.7.0` 标签，也未执行完整发布验收。

## 计划纳入的变化

- 图片双图工作区改为点击画面或按空格手动切换 A/B；打开模式时默认显示 A。
- 移除背景循环按钮和快捷键，保留深色、棋盘格、黑底和白底的直接选择。
- 图片差异模式统一在一个显示当前选项的菜单中；暂时隐藏不能使用的淡化入口。
- 顶部 A/B 提示限制在视口内，修复右侧文字截断。
- 保留 `c30886b` 基线中的高位深图片取样与视频双源指标工作流。

## 发布前验证

本地开发构建、格式检查、静态检查和自动测试不替代 Release 构建、ZIP/MSI
打包、真实 D3D11VA 性能、安装升级与关机压力门禁。发布候选标签将触发这些门禁；
全部通过后才能对外发布。
