# CompareStation 2.2.0

本次新增视频最近打开历史，以及侧栏右键加入当前对比。仍是 Windows x64 的静音视频／
图片查看与比较工具，最多三个视频源，不解码或播放音频，不新增字幕或项目文件。

## 新增与修复

- 普通文件菜单／Explorer 成功打开单视频后，侧栏显示所在文件夹；最近打开保存最多 50 个
  成功单视频的路径，支持去重、中文路径和完整路径提示。失败尝试、图片和多源比较不写入历史。
- 点击侧栏文件打开新的单视频任务；右键可选择「打开为新单视频任务」或「加入当前视频
  对比…」。追加保留当前来源顺序与参考源，确认窗口允许明确调整，Escape 取消不提交。
- 追加在确认和实际执行时复核当前来源、参考、打开代次与候选文件身份；删除／替换文件或
  切换会话后拒绝旧追加。缺失文件、零源或满三源显示禁用原因。
- 修复历史列表重建时菜单依附旧行的问题，保持冻结的目标 URL；侧栏菜单显示期间统一拦截
  播放、逐帧和打开快捷键。
- 保留本地 main 已有的按文件身份恢复播放位置、源顺序调整、启动提示及播放器悬停门控。
- 片段导出使用统一时间基准规划与复制非零起点片段，避免开头偏移；坏点占比显示修复也包含在内。
- 修复单实例启动代理的连接销毁回调：客户端只读取 PID 即断开或退出时，关闭过程不再访问
  已销毁的接收缓存。原始故障用例修复前稳定触发访问异常，修复后连续 100 次通过。

历史保留已移动／删除的路径，打开失败保留当前画面；不自动清理、递归扫描、生成缩略图、
监视目录或在视频结束后连播。文件身份复核使用路径、大小与修改时间，不保证识别刻意保持
这些信息不变的内容篡改。

## 下载与升级

- `CompareStation-2.2.0-windows-x64.zip` 是唯一软件包，解压后运行 `CompareStation.exe`。
- `SHA256SUMS.txt` 提供 ZIP 的 SHA-256 校验值。
- 升级前关闭旧应用，解压到独立的新目录并启动新版一次，使当前用户右键入口指向新目录。
  本版本 shell DLL 为 `CompareStationShell-2.2.dll`，不要只替换旧目录里的 EXE。
- 此版本为未签名构建；SHA-256 校验完整性，不证明发布者身份。
