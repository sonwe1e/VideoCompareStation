# CompareStation 2.7.0

2.7.0 是性能版本：围绕播放器启动与播放流畅度做了一轮系统优化。产品范围不变——
Windows x64 的静音视频／图片查看与比较工具，最多三个视频源；不解码或播放音频，
不新增字幕或项目文件。

## 播放流畅度

- 播放节奏定时器改用 Windows 高分辨率等待定时器：原先的等待原语受约 15.6 毫秒的
  系统定时器粒度影响，会吞掉 60 fps 的 14 毫秒准备提前量，120 fps 下提前量只剩
  半帧、节奏系统性偏晚；现在唤醒粒度为亚毫秒，60/120 fps 的帧节奏不再受系统
  定时器粒度拖累。
- 播放状态遥测（每帧计数、速率、滞后、追跑）改走独立通知并按约 4 Hz 节流：
  之前每一帧都会触发全量界面绑定重算，三路对比时时间线标记（最多 256 个）每帧
  销毁重建；现在播放期间界面只按节流节奏刷新。异常状态不等待——新出现跳帧、
  开始追跑、滞后进入 200 毫秒显示阈值时立即更新；暂停与逐帧步进不受节流影响。
- 界面投影集合按输入缓存：源媒体信息、时间线对齐标记、兼容性结论只在对应输入
  变化时重建，稳态播放期间复用共享副本，不再每帧全量重建与深比较。
- D3D11VA 零拷贝渲染的着色器资源视图随解码表面缓存：三路 1080p60 播放每秒
  省下约 360 次重复创建（120 fps 翻倍），设备换代时随资源一并失效。

## 打开与首帧

- 多源对比打开（以及换源、加源）改为并行开箱各路解码器：原先两三路视频要串行
  完成 2N 次解码器初始化，全部叠加进首帧延迟；现在各路并行初始化，失败或取消
  时的整体回退语义不变。
- 同一路的主解码器与精确解码器只做一次文件身份验证：第二次复用第一次刚验证的
  结果，不再对同一文件重复读取并哈希首尾各 1 MiB；流几何一致性检查仍逐次执行。
- 首次打开新视频时，时间线索引（.dvsi）的写盘与读回校验移出打开关键路径，在
  后台完成；发布前读回验证与原子替换的事务语义保持不变。

## 其他改进

- 播放中不再执行注定被丢弃的时间轴缩略图抓取（暂停与逐帧步进的抓取保留）；
  悬停缩略图缓存改按插入顺序逐出，回看刚看过的帧不再重新解码。
- 与播放并发的序列对齐分析线程降为低于普通优先级，不再与解码、冷定位争抢
  磁盘与 CPU 余量。
- 软件解码回退路径的像素格式色彩配置改为仅在输入变化时重新设置，每帧转换
  语义不变。
- 时间轴悬停弹窗、状态栏等界面文本在播放期间的重算频率随之显著下降。

## 工程与文档

- 性能审计发现的后续项已按稳定编号记入问题台账（PERF-01 至 PERF-04）：
  CPU 解码回退路径的上传资源池化、协调层前视深度、事件队列队头阻塞与测量
  工具增强，均为待证据/待决策的后续批次，不在本版本。
- 真实环境验证文档修正了性能门禁的可执行入口（GUI 可执行文件，而非只处理
  冒烟检查的 CLI）。

## 已知边界

- 本版本的播放性能结论来自行为测试与本机启动 A/B 测量；发布级的 1080p60 五分钟
  与 1080p120 双/三路硬件门禁需在带 ≥120 Hz 物理显示器的交互会话上按既有协议
  复跑确认。

## 打包校验

- 包为 Windows x64 免安装 ZIP，内含 EXE、CLI 与本版本的 `CompareStationShell-2.7.dll`
  （按主／次版本命名）；不要只替换旧目录里的 EXE。
- 包校验 16/16 通过：版本号、版本派生 shell 库、启动自注册代码与菜单文案、
  双击注册入口与 ASCII+CRLF 形状、INSTALL.txt 自注册/卸载/逃生说明。
