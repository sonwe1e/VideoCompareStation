# CompareStation 1.8.1

CompareStation 1.8.1 是交付方式的修订版：应用与 1.8.0 完全相同，改变的是发布产物和右键菜单的
获取方式。

---

## 主要变化

### 交付

- **不再提供 MSI**。安装程序带来的维护面（WiX 模板与 CPack WIX 配置、机器级安装冒烟测试、
  下载上一版 MSI 的升级门禁、每个发布 runner 上的 WiX/.NET 工具链、以及写死单一版本的发布
  守卫）高于它带来的收益。发布产物只剩 Windows x64 ZIP 与 SHA256SUMS。
- **资源管理器右键命令改随 ZIP 交付**。包内新增 `RegisterExplorerCommand.ps1`，为当前用户把
  `.mp4` / `.mkv` / `.mov` / `.avi` / `.m4v` 的「Compare with CompareStation」注册到
  `HKCU\Software\Classes`（Explorer 会合并进 HKCR），不需要管理员权限；`-Uninstall` 可撤销。
  它复用 `src/shell_windows` 里原有的 Explorer 命令扩展，行为与安装版一致：选中 1–3 个视频
  时只拉起一个进程并按其命令行列参数，目录、网络路径与超过三个文件时该项自动隐藏。
- 包内新增 `INSTALL.txt`：免安装说明、右键注册与卸载命令、Windows 11 需在「显示更多选项」
  中查找该项，以及「注册的是本目录绝对路径，移动目录后需重新注册」的注意事项。

### 应用

本版本不含应用侧改动。`CompareStation.exe` 与 `CompareStationCli.exe` 与 1.8.0 同源，尺寸
完全一致（2,260,480 / 553,472 字节），仅因重新链接产生 PE 时间戳级差异。

---

## 发布范围

CompareStation 面向本地素材的静音视觉质量审查，支持 H.264、HEVC、MPEG-4 Part 2 与 SDR 视频；
音频与字幕不在当前范围内。发布产物为 Windows x64 ZIP 与 SHA256SUMS。本版本保持未签名：
Windows 可能显示 Unknown Publisher 或 SmartScreen 提示，SHA-256 仅用于校验产物完整性。

功能范围、两条区间导出限制与其余已知限制见
[1.8.0 发布说明](v1.8.0.md)。
