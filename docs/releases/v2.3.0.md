# CompareStation 2.3.0

本次集中修复观看与操作体验的四处缺陷：竖屏视频的倍率读数与一键真实尺寸、来源条拖拽
显示排序、侧栏键盘目标可见性、连续倒退逐帧互相取消。仍是 Windows x64 的静音视频／
图片查看与比较工具，最多三个视频源，不解码或播放音频，不新增字幕或项目文件。

## 新增与修复

- 修复竖屏视频的倍率徽标与一键真实尺寸：倍率按实际视频内容尺寸计算，不再把面板留白
  或分割遮罩计入宽度，也不再固定读取第一个槽位。旧版在 800 × 600 视口显示 1080 × 1920
  竖屏时把约 31% 报成 74%，点击真实尺寸也不是物理 1:1；现在跟随当前首显示源、ROI 与
  旋转计算，移动分割线不改变倍率，非方形像素分别显示横/纵百分比，未到 1:1 或触及
  64× 上限时不误标真实尺寸。缩放、平移、分割线与再次点击适应窗口的交互保持不变。
- 恢复来源条的指针拖拽显示排序：按住来源牌拖过其它牌后释放，来源条按新顺序排列，
  拖动中的牌置于其它牌上方；在自己位置内小幅拖动不会误排序；普通点击仍选中，源菜单、
  右键与 Ctrl 拖动不触发排序；禁用/隐藏、拖拽被其它手势接管、拖动中源列表变化都会
  取消旧排序意图。排序只改显示顺序，A/B/C 身份、GT、参考与时间轴归属不变。
- 侧栏（当前文件夹／最近打开）键盘导航可见：方向键移动的键盘目标显示细边框，当前
  播放项保持填色，Enter 打开边框对应的文件；焦点直接落在某一行时，Menu／Shift+F10
  菜单作用于该行而不作用于旧行；焦点离开列表后边框消失、选择保留。单击、右键确认、
  历史与失败处理不变。
- 修复连续倒退逐帧时两次请求互相取消：前一帧尚未完成解码时再按一次 ←，旧版会提前
  提交更前一帧并撤销仍要显示的帧，两次按键都落入取消、画面停在原帧；现在后继倒退
  请求等待当前帧就绪后立即预备，快速连按 ← 或短按住 ← 每次各退一帧。正向步进、
  Exact／seek、解码与文件身份校验行为不变。

## 验证

本文件随 v2.3.0 候选提交维护。四个修复合入后，在 Windows／MSVC 19.44／Qt 6.11.1 完成
本地验证：dev 预设全量 962 项 0 失败（7 skipped/disabled 为既有状态），四个修复的定向
集合 107/107（播放协调器／预取 92、视口倍率 5、侧栏键盘 2×19、来源条拖拽 8×26），
format-check 346 文件、lint 通过。过程中修复三处测试基建在 Windows 上的问题：来源条
套件超时放宽到 60 秒（真实窗口单轮约 21 秒）、侧栏菜单测试等待内容列首帧布局后再点击
（修复前 10/15 轮固定 4 例红，修复后 24/24）、视口倍率测试补齐部署的 qml 导入路径；
另将倒退修复新增的协调器用例补过 clang-format（详见工程台账 2026-10-08 条目）。组件层
验证使用真实窗口与真实指针/键盘事件；无头会话无法驱动全 App 交互步进，该项留待有显示
会话，不计为通过。硬件／性能、打包与升级门禁由标签触发的 CI 执行。

## 下载与升级

- `CompareStation-2.3.0-windows-x64.zip` 是唯一软件包，解压后运行 `CompareStation.exe`。
- `SHA256SUMS.txt` 提供 ZIP 的 SHA-256 校验值。
- 升级前关闭旧应用，解压到独立的新目录并启动新版一次，使当前用户右键入口指向新目录。
  本版本 shell DLL 为 `CompareStationShell-2.3.dll`，不要只替换旧目录里的 EXE。
- 此版本为未签名构建；SHA-256 校验完整性，不证明发布者身份。
