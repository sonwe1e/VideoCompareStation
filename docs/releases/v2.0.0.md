# CompareStation 2.0.0

CompareStation 2.0.0 是性能与可维护性版本：启动路径少做约 60 ms 的实例化工作，五个 UI
子树改为按需构建，测量协议补齐三层取数（外部窗口计时 / 内部里程碑 / 首帧 trace），并删除
约 8,100 行冗余与第三方代码。全部行为契约保持：767/767 测试、qmllint --max-warnings 0、
clang-tidy 与格式门禁贯穿每一批改动。

---

## 主要变化

### 启动更快：QML 实例化段 −59 ms

启动里程碑把「窗口出现 → 事件循环起步」精确归因到四个段，其中 **QML 装载+整树实例化段**
（577 ms，占预事件循环时间的 65%）是唯一可通过延迟加载削减的段。2.0.0 分两批把它移出启动路径：

- **弹窗与对话框**（导出对话框、视频输入对话框组、快捷键帮助表）：首次打开时才构建，
  之后常驻。启动后立即存在的 objectName 契约全部保留（根节点常驻或断言随打开移动）。
- **图片工作区与检查器**：视频评审会话不再构建 2874 行的图片工作区树（~150 个命名对象）
  和检查器标签树；首次激活/首次打开检查器时一次性构建（实测 ~42 ms，远低于感知阈值），
  之后常驻。

| 段（无文件，中位，ms） | 1.9.0 基线 | 2.0.0 | Δ |
|---|---|---|---|
| QML 装载+整树实例化 | 577.3 | **518.2** | **−59.1** |
| spawn → 窗口可见 | 660.5 | 579.9 | −80.6 |
| spawn → 事件循环起步 | 888.6 | 757.9 | −130.7 |

跨日数字含环境漂移（同机同素材下 GPU 初始化段本身日间波动 ~25 ms）；每批改动均以
**同日背靠背 A/B** 验证：延迟加载两批的端到端收益合计 **−56.0 ms**（−18.1 + −37.9），
与 QML 段削减一致。复现：`pwsh tools/testing/measure-startup.ps1 -Label <label> -Rounds 5
-Warmup 1`，数据存于 `out/startup-measurements/`。

带文件启动首次有了精确的首帧时间（playback trace kind 0/4/8 与里程碑同钟对齐）：
窗口可见 574.7 → 事件循环 762.2 → 命令接受 794.3 → **首帧提交 835.1 ms**（中位）。

### 包更小：−8,100 行，第三方解码器 −1 项

| 项 | 1.9.0 基线 | 2.0.0 |
|---|---|---|
| ZIP | 26.63 MiB | **26.60 MiB** |
| 解压 | 66.42 MiB | 66.36 MiB |
| 条目数 | 310 | 310 |
| 主程序 | 2,254 KB | 2,196 KB |

stb_image（276 KB 第三方头 + 59 行包装）被删除：生产链路早已由组合根注入 FFmpeg 解码器
（部署包不带 qjpeg/qwebp 插件，stb 是 JPEG 的后备），FFmpeg 的格式覆盖是其超集；测试对
stb 路径零断言。

### 行为保持与单源化

三处**已经实际漂移**的重复实现被合并为单源（几何公式、持久化字符串表、文件名标签），
四处语义色字面量归位主题 Token；删除清单与每批的安全证据见
`docs/engineering/startup-performance-v2.md` 的 Step 7 一节。调试与自动化能力新增：
`DVS_STARTUP_TIMING` 里程碑（16 个）与 `DVS_PLAYBACK_TRACE` 首帧层默认关闭、零开销。

### 已验证不成立并记录的方向

计划中的另外两条优化路径经实测**架构性取消**，避免未来重蹈：QML 预编译（编译段 ≤20 ms，
收益为零、体积 +2.9 MB）与启动请求提前（打开命令被 `graphicsReady` 门拒绝——媒体打开
依赖 show() 内创建的 D3D11 设备，主线程无法更早提交）。首次打开的解码器竞争实测未出现
（单源与三源并发首开均为 D3D11VA 硬解、零回退）。

## 发布范围

CompareStation 面向本地素材的静音视觉质量审查，支持 H.264、HEVC、MPEG-4 Part 2 与 SDR 视频；
音频与字幕不在当前范围内。本版本保持未签名：Windows 可能显示 Unknown Publisher 或
SmartScreen 提示。安装即解压 ZIP；资源管理器右键命令由包内
`RegisterExplorerCommand.ps1` 按用户注册，`-Uninstall` 可撤销。
