# CompareStation 1.8.0

CompareStation 1.8.0 是 1.7.0 更名与图像审查基线之后最大的一次功能版本。视频侧补齐了
入点／出点区间、循环播放与无损流拷贝导出；图片侧从「只能看」扩展到裁剪、缩放、填充
画布、画笔、马赛克、填充／清除与箭头／矩形／文字标注，全程可撤销；比较界面新增候选
快捷切换、差异分级与按住看原图、一键复制带标注对比图；图片工作区与走带条的命令布局、
身份呈现和状态读数按使用体验重做。

---

## 主要变化

### 视频：区间与导出

- **走带条区间行**：入点／出点／播放区间／循环／清除五个芯片加一行状态文字，三态为
  `未设区间（I / O 设点）`、`入 42 · 出 —（区间无效）`、`入 42 · 出 48 · 7 帧`（循环时
  追加 ` · 循环`）。区间是闭区间，只设一端或出点早于入点时明确提示区间无效并禁用
  播放／循环。区间真值仍在 `ReviewShellController`，芯片只做投影；`I`／`O`／`\`
  快捷键语义不变，停止循环只清 loop 标记、保留端点。
- **区间导出（无损流拷贝裁剪）**：把入点到出点导出成可独立播放的片段。按包复制，
  不解码、不重新编码，因此画面与源逐帧一致，分辨率、帧率与编码原样保留；导出固定取
  规范源（时间线主源）的路径与规范媒体时间。两条限制在对话框内写明而不是留待事后
  发现：起点对齐到前一个关键帧（片段可能比入点更早开始），B 帧素材结尾可能多出几帧。
  写临时文件、成功后才改名，失败或取消不留半成品；导出中显示百分比并可随时停止。
- **候选快捷切换**：以固定参考源为基准一键切换候选。
- **差异分级与按住看原图**：差异按钮提供多个显示口径，按住可临时查看原图。
- **一键复制带标注对比图**：按设备像素裁剪视口并附加中性灰说明条（源名称、观察模式、
  当前帧、活动比较对与阈值、时间戳），可进剪贴板或另存为 PNG；失败时不覆盖既有文件。

### 图片：轻编辑套件

- **编辑会话**：从已提交的解码缓冲派生工作副本，原图保持不变、编辑结果另存副本，
  源文件自身路径被显式拒绝为保存目标；派生通道视图永不作为编辑源。
- **裁剪**：自由框选，几何以图像像素表达；缩放或平移不会让选区、笔画、标注错位。
- **缩放**：按输入像素尺寸重采样，默认锁定比例，可选平滑或像素级插值，标注几何与
  文字字号按比例缩放（下限 1px）。
- **填充画布**：原图居中放入更大的画布，余量填黑／白／中灰／透明，标注随居中偏移
  平移；画布小于原图时拒绝，透明填充仅在图像带透明通道时可用。
- **画笔／马赛克／填充／清除**：颜色、粗细、不透明度与块大小可调；填充为纯色块、
  清除为透明像素。
- **箭头／矩形／文字标注**：平面标注列表（上限 64），可点选、拖动、删除。
- **撤销／重做与保存**：上述几何与像素操作各算一个撤销步；历史改为带 256 MiB 字节
  预算的有界实现，刚压入的步骤不会被剪掉。

### 图片：工作区与比较呈现

- **命令区两行 Flow**：A 行为文件与视图（打开图片、打开图片对、关闭、适应窗口、
  100%、重置视图），B 行为对比模式芯片与通道／背景选择；960px 最小宽度下自然换行，
  不再横向溢出，分隔符随相邻按钮可见性联动。
- **视口身份牌**：每个视口左上角显示文件名与「槽位·尺寸·格式·α·数值审查路径」，
  悬停显示完整路径；分割线模式与淡化模式统一为同款呈现。身份牌纯展示，不拦截
  画布平移与框选。
- **状态条**：左侧缩放／像素读数，右侧转换、重采样与 α 直通徽标加操作提示。
- 内容区默认中性灰棋盘格背景；通道视图按真实字节序读取；淡化模式启用。

### 图片：分析与指标

- 图片差异拆成「每对素材一次分析」与「按模式／增益渲染」：增益（1–16）只放大显示
  变体，统计始终是原始 8-bit 差值。
- 指标会话绑定文件身份并统一尺寸不匹配策略；对齐、时间线预览与图像检查改进。

## 发布范围

CompareStation 面向本地素材的静音视觉质量审查，支持 H.264、HEVC、MPEG-4 Part 2 与
SDR 视频；音频与字幕不在当前范围内。发布产物为 Windows x64 ZIP、MSI 与 SHA256SUMS。
本版本保持未签名：Windows 可能显示 Unknown Publisher 或 SmartScreen 提示，
SHA-256 仅用于校验产物完整性。

Draft Release 仅在精确 tag／版本验证、Debug 与 Release 检查、Quality、D3D11VA 硬件与
性能门禁、上一版本升级、packaged smoke、shutdown soak 与 FrameProvider 资源退休压力
测试全部在目标 release SHA 上通过后创建。

## 已知限制

- 区间导出按关键帧对齐起点，精确成帧裁剪需要重新编码阶段，本版本不做；B 帧素材的
  结尾可能比出点多几帧。
- 图片编辑不含图层系统、批量处理与内容感知补图；填充画布不支持任意锚点。
- 关键帧对齐的端到端验证目前只覆盖单关键帧素材上「起点回到文件开头」这一种前滚情形。
- 真实 D3D11VA 播放性能与安装升级／关机压力门禁由标签触发的 CI 在目标提交上执行，
  本地 Release 构建与 ZIP 打包不替代这些门禁。
