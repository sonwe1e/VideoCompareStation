# CompareStation 2.5.2

2.5.2 新增图片工作区标签页，并把 2.5.1 之后的窄窗口布局、对比图导出、Wipe 键盘操作和
启动／图片编辑修复纳入正式包。仍为 Windows x64 的静音视频／图片查看与比较工具，最多三个
视频源；不解码或播放音频，不新增字幕或项目文件。

## 图片工作区标签页

- 一个标签是一次图片审查任务（单图或一对 A/B），不是一张孤立文件。打开单图、图片对，
  或从资源管理器／命令行传入图片默认新建并激活标签；同一素材再次打开只切回已有标签，
  不重复解码。
- 每个标签保留自己的配对、解码缓冲、差异缓存、缩放／平移和比较模式；切换标签不会丢弃
  另一个任务的观察状态。
- `Ctrl+W` 关闭当前标签，`Ctrl+Tab`／`Ctrl+Shift+Tab` 循环切换；关闭活动标签后选相邻
  标签，关闭最后一个回到视频任务或空态。加载失败不留下空标签。
- 标签条显示文件名、加载状态和未保存编辑圆点；最多 12 个标签，总工作集沿用单对原有的
  1.5 GiB 硬顶，超限明确拒绝，不静默淘汰。
- 标签不跨重启保存，继续不引入项目文件。未保存编辑仍只有一个会话，按素材路径归属到
  标签：可以带着未保存编辑切走，但关闭该标签或在另一个标签开始新的编辑会被拒绝并说明
  原因，切回原标签恢复编辑视图。
- 一次选择三张以上图片仍按原规则拒绝；连续打开请逐次进行。

## 窄窗口布局（UX-13）

- 窗口高度不超过 680 像素时进入紧凑 chrome：视频源条与比较模式栏合并为一行，视频走带条
  使用紧凑排布；图片工作区的命令面板折叠，像素读数移出状态栏，避免底部控件互相遮挡。
- 宽窗口布局保持原样；紧凑层只改变布局密度和合并方式，不放宽媒体比较、快捷键或像素检查
  语义。

## 导出与交互

- 新增裸对比图导出和「另存为对比图」入口：保存当前比较画面本身，不叠加审查 UI。
- Wipe 分割线支持键盘调整；画面叠加元素改用主题令牌，保持深色主题下的对比度。

## 启动与图片编辑修复

- 启动画面改为品牌化启动画面（图标、标题、版本号、不定进度条），并等到第一帧交换后才
  撤下；后台线程自超时兜底，启动失败时不会把置顶 splash 永久留在桌面。
- 图片缩放／填充对话框的宽高输入改为真实提交：键入数字后按 Enter 或失焦即写入模型，
  锁定比例时另一侧联动；修复「只改数字、应用仍用旧尺寸」的路径。

## ZIP 载荷与升级

- `CompareStation-2.5.2-windows-x64.zip` 是唯一软件包，完整解压后运行 `CompareStation.exe`。
- `SHA256SUMS.txt` 提供 ZIP 的 SHA-256 校验值。
- 保留必需的 app-local CRT／UCRT、Qt／FFmpeg、QML Basic 样式、资源、许可证与右键注册
  入口，不附带开发符号、测试素材、额外运行库安装器或未使用的图形编译器。
- 升级前关闭旧应用，解压到独立的新目录并启动一次，使当前用户右键入口指向新版。
  本版本 shell DLL 仍为 `CompareStationShell-2.5.dll`（按主／次版本命名）。
- 此版本为未签名构建；SHA-256 校验完整性，不证明发布者身份。
