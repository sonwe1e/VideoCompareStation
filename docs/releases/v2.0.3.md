# CompareStation 2.0.3

2.0.3 是针对 ZIP 升级与资源管理器右键打开的兼容修复版本。视频／图片查看与比较、静音范围、
解码和差异指标不变，本次没有新增项目浏览或其他工作流。

## 主要修复

### 升级后清理旧右键入口

启动新版一次，或执行新版包内的注册脚本后，会接管当前用户的右键菜单，并清理指向
CompareStation 的旧入口，只保留一套规范注册。

- 不再因为旧入口与当前入口的键名相同就跳过清理；判定保留的是完整注册路径。
- 覆盖扩展名关联、SystemFileAssociations、版本化 ProgID 与带版本号的旧入口。
- 识别旧 `VCStation.exe` 启动命令；规范入口上遗留的普通 `command` 子键也会移除。
- 注册和卸载使用同一套归属判断，不会误删其他播放器的菜单，也不会因为其他程序的参数提到
  `CompareStation.exe`，或程序名称只是相似，就把它当作本应用。
- 修复或清理后通知 Windows 更新关联缓存，应用侧通知不等待 Explorer 响应。

**仅解压、不运行不会触发接管。** 旧版软件目录不会被删除，Windows 默认播放器不会改变。
用户显式关闭右键菜单的选择仍会保留。

### 右键启动不再固定寻找缓存 DLL 的旧目录

资源管理器可能在升级后仍持有旧目录的右键扩展。过去该扩展固定从自己的目录寻找
`CompareStation.exe`；旧程序已被移除时，启动会失败，可能表现为 Windows 提示找不到文件。

现在每次右键调用都从当前用户注册的 shell 目录定位程序；没有注册时才回退到 DLL 所在目录。
回归测试真实加载旧目录的 COM DLL，再把注册切到新目录，旧目录不放 EXE，验证实际启动新版
程序，并完整传递含中文、空格和 `&` 的 MP4 路径。

这修复的是上述右键升级故障，不将其他入口、实际缺失文件或不支持的媒体格式混同为同一个原因。

## 验证与发布门禁

- 本次修复的应用启动与 shell 回归测试 66/66；注册／卸载脚本检查 85/85，强制验证执行数量。
- 13 个故障变异均被对应测试检出（C++ 8、脚本 5）；恢复控制组通过。
- 标准发布要求 Release 全套测试、format-check、lint、打包版本与内容校验、三种 DPI 的
  packaged-smoke、shutdown-soak，以及交互桌面上的 hardware-d3d11／performance-d3d11 门禁。
  不复用 2.0.2 的硬件证据，也不把离线 runner 当作性能通过；候选提交的实际结果随发布页提供。

## 下载与升级

- `CompareStation-2.0.3-windows-x64.zip`：唯一软件发布包，解压后运行 `CompareStation.exe`。
- `SHA256SUMS.txt`：ZIP 的 SHA-256 校验值。
- 从 2.0.1／2.0.2 升级时，请先运行 2.0.3 一次，再使用资源管理器右键入口。
- 仍是**未签名**的 Windows x64 构建；SHA-256 用于完整性校验，不证明发布者身份。

## 已知边界

- 自动清理限于当前用户 HKCU；机器级 HKLM 遗留注册需要管理员权限处理。
- 真实 COM 启动与注册表形状已有回归验证，受影响用户机器的 Explorer 菜单观感仍需复核。
- 新代码不能改写已经加载到 Explorer 进程中的旧版 DLL 指令；关联变更通知会请求 Windows 刷新，
  缓存 COM 测试覆盖的是本次修复后的扩展实现。
