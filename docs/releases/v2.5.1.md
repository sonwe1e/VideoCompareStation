# CompareStation 2.5.1

2.5.1 是维护版本：单图打开后可在同目录内连续翻页；同时清理了已证实无调用者的代码，
并修复循环播放跳帧漏计、启动图移交竞态、协议仓库生命周期、Explorer 右键回调异常与
渲染器释放后残留确认五处缺陷。仍为 Windows x64 的静音视频／图片查看与比较工具，最多
三个视频源；不解码或播放音频，不新增字幕或项目文件。

## 单目录图片连续查看（FLOW3 首个切片）

- 单图打开后，`←`／`→`／`↑`／`↓` 在同目录内按自然序翻到上一张／下一张，`Home`／`End`
  到首尾；工具栏显示「当前 / 总数」。不含递归扫描、媒体库、自动轮播或多图模型。
- 只列当前目录，扩展名与图片路由使用同一来源（13 种）；目录超过 10000 张时关闭浏览而
  不是给出截断序列，避免「下一张」不是真正的下一张。首尾不绕回。
- 每次翻页重新扫描目录，新增或删除的文件在下一步生效；窗口重新获得焦点时刷新序号与
  邻居列表，游标为空（图片对或双文件夹任务）时不动。
- 有配对列表时方向键仍逐行切换配对，原行为优先；无配对列表时才翻目录。
- 当前图片处于未保存轻编辑状态时拒绝翻页与换图，提示先另存或结束编辑；干净会话提交
  新图时自动结束旧编辑会话，避免编辑态停在另一张图上。
- 视频文件夹列表与图片游标共用自然序实现：数字按量级、大小写折叠、非 ASCII 按码点
  （D-013），不引入 ICU 或拼音排序。

## 修复

- 循环播放回到区间起点后，跳帧统计不再永久漏计：每次发布都成为下一次基线，回卷本身
  不算跳帧。此前 90→40 回卷后，40→45 的缺口会一直漏到播放结束。
- 启动图在窗口 `show()` 之前移交。此前 `sceneGraphInitialized` 处理器可能读到空指针，
  并与 GUI 线程的赋值构成数据竞争；早期关闭也会丢失启动图。
- 插值协议仓库的构造顺序调整到窗口之前，保证其生命周期长于持有裸指针的 QML 控制器；
  退出时在途加载不再可能访问已销毁对象。
- Explorer 右键菜单的 `GetTitle`／`GetToolTip` 在内存分配失败时返回错误码而不是终止
  Explorer 宿主进程；输出指针先置空再复制。
- 渲染器 `releaseResources()` 一并清空待确认 ACK、最高序号与关闭标记；换设备后不再
  重放旧代际确认或永久返回 `Closed`。

## 清理（不改变行为）

- 删除 14 组零调用代码，净减约 480 行：`decodeStillImageFile`、`IssueRecordRepository`
  的三个死方法、遗留双栏几何（`SurfaceSplitLayout`／`computeSurfaceSplit`／整数版
  `aspectFitRect`）、`MemoryTraceSink`、未接线的对齐缓存键及其 FNV 辅助、只写时间戳字段、
  `supportsRoi`、`SessionSnapshot` 不可达分支、死 `Q_INVOKABLE`／诊断属性／属性链、
  三个死 context property 与 5 个 QML 死属性及主题令牌。
- 删除 2 个结构性无效的禁用测试（驱动假内核的区间基线、把未实现的 seek 合并写成期望
  值的基线）；时间轴无障碍用例改为校验 Slider 角色、名称与 Tab 焦点并启用；Wipe 手柄
  用例修正附加属性读取方式与角色枚举。禁用测试由 4 个降到 1 个，保留项对应尚未实现的
  键盘／读屏能力。
- 更正 `docs/agent-guide.md` 中指向已删除文件与旧架构的描述。

## 验证

软件验证绑定本次 Release 构建（MSVC 14.44.35207、Qt 6.11.1、FFmpeg 8.1.2、SDK
10.0.26100.0 运行时）。未放宽测试断言、超时或性能阈值。

- Release 预设 **1449 项**：**1446 通过、3 项在 `-j 8` 并发下超时或偶发失败，串行重跑
  全部通过**，0 项断言失败。`quality.build-scripts` 与 `app.playback-trace-gate-schema`
  是并发下的超时（后者脚本自身输出 `assertions=73`，单跑 14.5s）；`ui.video_file_sidebar.Basic`
  为既有的 hover 偶发失败，与本轮改动无关。
- `packaged-smoke` 三档缩放（100／125／150）弹出控件像素检查 **3/3** 通过；`shutdown-soak`
  **20 次**重复打开与关闭通过。
- 版本与包身份：`tools/release/verify-release-version.ps1 -Tag v2.5.1` 校验 GUI 文件版本、
  产品版本与 ZIP 文件名同项目版本一致；CPack staging 与运行时载荷门禁在打包时执行。
- `format-check` 检查 **432** 个 C++ 文件与生产 QML，通过；C++ lint（clang-tidy，110 个
  生产翻译单元，`platform_windows` 按项目策略排除）与生产 QML `--max-warnings 0` 通过。
- **未执行**：真实 D3D11VA 硬件门禁、`performance-d3d11` 与物理显示／干净 Windows 验收。
  本机为日常设备，按[测试环境分离](../engineering/test-environment-separation.md)不自动启动
  这些门禁；未运行的门禁不记为通过，也不据此宣称 FPS、seek 延迟或硬件性能达标。

## ZIP 载荷与升级

- `CompareStation-2.5.1-windows-x64.zip` 是唯一软件包，完整解压后运行 `CompareStation.exe`。
- `SHA256SUMS.txt` 提供 ZIP 的 SHA-256 校验值。
- 保留必需的 app-local CRT／UCRT、Qt／FFmpeg、QML Basic 样式、资源、许可证与右键注册
  入口，不附带开发符号、测试素材、额外运行库安装器或未使用的图形编译器。
- 升级前关闭旧应用，解压到独立的新目录并启动一次，使当前用户右键入口指向新版。
  本版本 shell DLL 仍为 `CompareStationShell-2.5.dll`（按主／次版本命名）。
