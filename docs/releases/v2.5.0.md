# CompareStation 2.5.0

2.5.0 更新图片像素观察、Alpha 过滤与视频比较工作流，修复底部控件无法操作、局部画面
语义混乱和侧栏布局抖动等问题。本次也包含 2.4.0 开发阶段的图片轻编辑与视频观察一致性
更新。仍为 Windows x64 的静音视频／图片查看与比较工具，最多三个视频源；不解码或
播放音频，不新增字幕或项目文件。

## 图片观察与编辑

- 像素读数使用底部整行宽度，鼠标离开画面后保留当前素材的最后一个有效样本，可移到
  工具栏切换整数／归一化浮点或复制 RGB、RGBA、Hex。更换素材后旧样本失效；双图明确
  选择 A 或 B，差值保留正负号，16-bit sidecar 另行标明位深与转换语义。
- Alpha 过滤提供开关、0–255 滑块、精确输入与重置；开启后切换到可应用过滤的 RGB
  观察，阈值实际更新显示。过滤仅改变观察图，不改原始像素、采样值与差异统计。
- 支持图片标签右键关闭 A／B、只替换一侧与对调；关闭 A 时保留 B 的文件身份和内容。
  图片标签增加内部留白，统一入口与数值／颜色复制反馈。
- 图片轻编辑提供镜像、翻转与旋转，像素与标注一起变换，并可撤销；单图与裁剪十字线、
  光标锁定平移、平滑缩放和连续裁剪边界修复一并交付。

## 视频查看与比较

- 局部比较保留上方全画面总览，下方额外窗口显示框选 ROI；主画面的指针映射、选框和
  像素网格使用总览坐标，避免上下两处同时裁成局部。切换并排／划线／局部会退出直看
  A／B 和锁定 GT 原图状态，再次选择当前比较模式也能返回比较布局。
- 入点、出点及有效区间的播放／导出入口保持可见，工具组与相邻帧条对齐。导出采用无损
  流拷贝，起点受关键帧对齐约束；不能将其理解为任意帧精确重编码裁剪。
- 文件与历史侧栏固定宽度，四个操作采用两行两列等宽布局；删除拖宽分隔条，避免调整
  宽度时整个界面反复重排。视频标签通过右键替换或关闭，删除重复的三点按钮。
- 分割线可切换左右／上下，原画面可在最近邻且物理放大达到 800% 时显示像素网格；
  区间支持往返观察。实际播放速度由运行状态决定，不以所选倍率代替性能证据。
- 视频像素探针绑定已呈现帧组和异步请求身份，播放时冻结读数；GT 直看明确来源，问题
  记录恢复等待匹配的打开／比较对／seek 终态。改进按住逐帧、键盘焦点与操作反馈。
- 修复菜单细边缘透出背景，并使包内菜单探针通过实际源标签查找右键菜单。

## ZIP 载荷与升级

- `CompareStation-2.5.0-windows-x64.zip` 是唯一软件包，完整解压后运行 `CompareStation.exe`。
- `SHA256SUMS.txt` 提供 ZIP 的 SHA-256 校验值。
- 保留必需的 app-local CRT／UCRT、Qt／FFmpeg、QML Basic 样式、资源、许可证与右键注册
  入口，不附带开发符号、测试素材、额外运行库安装器或未使用的图形编译器。
- 升级前关闭旧应用，解压到独立的新目录并启动一次，使当前用户右键入口指向新版。
  本版本 shell DLL 为 `CompareStationShell-2.5.dll`，不要只替换旧目录中的 EXE。
